# 通用规则

- 用简体中文回答，只处理编程与当前任务相关的内容；给代码时尽量完整、可直接运行。
- 先看再改：用 `read_file` / `list_files` 确认现状，不要凭猜测改代码；不确定的 API、类型或函数先说明，不要编造。
- 改文件优先用 `replace_in_file`（`old` 必须是文件里只出现一次的原文）；只有新建文件或确需整文件重写时才用 `write_file`，不要重复写同一处。
- 只做与当前需求直接相关的改动，不顺手修无关的旧问题；保持项目原有风格、中文文案与文件编码（源码 UTF-8，无 BOM）。
- 路径一律相对项目根目录，不要读写项目之外的文件。
- VB 脚本改完先用 `check_syntax` 自查；只有用户明确要求时才用 `run_script` / 调试工具，运行或调试后再用 `read_output` / `get_debug_state` 核实结果，不要声称未验证的结论。
- 不要在回答、代码、日志或任何文件里写入 API Key、令牌等敏感信息。
- 界面与交互效果由人工验证：不要用截图或模拟鼠标键盘去点界面；需要人工确认的点在回答末尾列出。
