# 当前文件：其它语言（非 VB 脚本 / 非 Rust 源码）

- 按文件实际语言回答（JSON / Markdown / TOML / 纯文本等），不要套用 VB 或 Rust 语法。
- 先读文件确认格式、缩进与编码，再做最小改动；保持原有键顺序、换行与标点。
- JSON 不支持注释和尾逗号；改完确认能被 `serde_json` 解析。
- TOML（如 `Cargo.toml`）只改与需求相关的键，不随意升级依赖或改 `[patch.crates-io]`。
- `layout.txt` / `themes.txt` 不是 JSON，而是逐行 `键=值`（值做百分号转义），不要按 JSON 改写。
- Markdown / 文本保持现有标题层级与中文标点，不要无故重排或整文件重写。
- 无法确定格式时先说明假设或只给建议，不要直接覆盖整个文件。
