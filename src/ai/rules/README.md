# Q-IDE AI 规则

这里存放 Q-IDE 内置 AI 助手的固定规则。程序启动时会创建缺失的文件，但**不会覆盖**你修改过的内容。

- `common.md`：所有语言都会加载（工具用法、改代码与验证约定）。
- `vb.md`：当前打开的是 VB 脚本时加载（解释器语法、Win32 调用与调试约定）。
- `rust.md`：当前打开的是 Rust 源码时加载（Q-IDE 项目结构、GPUI 约束、测试与验证命令）。
- `default.md`：当前语言没有对应规则文件时加载。
- `<语言>.md`：可自行添加，例如 `json.md`；文件名使用编辑器识别出的语言名（`rust` / `vb` / `json` / `text` …）。

实际发送顺序：`common.md` + （`<语言>.md` 或 `default.md`）。

修改后**下一条消息立即生效**（每次请求都会重新读取），不需要重启 IDE。
把某个文件清空可以关闭对应的规则；删除文件会在下次启动时重新生成默认内容。
设置环境变量 `QIDE_AI_RULES_DIR` 可以改用其它目录（便于测试或多个 IDE 共享规则）。

文件为 UTF-8（无 BOM）。改规则时请保持中文原样；不要用 Windows PowerShell 5.1 的 `Get-Content` / `Set-Content` / `Out-File` 直接读写，以免中文被按 GBK 解码或写入 BOM。

规则越短越省上下文：只写模型容易做错、且在本项目里必须遵守的约定，不要把完整文档抄进来。
