# VB6 黄金脚本用例：用 `=== 用例名` 分隔，每段是一段完整的 VB 语句序列（可以用 Debug.Print）。
# 生成器会把 `Debug.Print` 换成写文件，并把每段包进独立的过程，因此各段之间的变量互不影响。
# 每段不能用 `End`（会终止程序）、不能声明与过程名冲突的东西。

=== for_counter_overflow
Dim i As Integer, n As Long, j As Long
On Error Resume Next
Err.Clear
For i = 32767 To 32767
    n = n + 1
Next i
Debug.Print n, Err.Number
Err.Clear
n = 0
For i = 32766 To 32767 Step 1
    n = n + 1
Next i
Debug.Print n, Err.Number
Err.Clear
n = 0
For i = -32768 To -32768
    n = n + 1
Next i
Debug.Print n, Err.Number
Err.Clear
n = 0
For j = 2147483647 To 2147483647
    n = n + 1
Next j
Debug.Print n, Err.Number
