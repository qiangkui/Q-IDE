# 快捷键与命令

快捷键定义在 [`src/app.rs`](../src/app.rs)（`init` 里的 `KeyBinding`）与 [`src/commands.rs`](../src/commands.rs)（命令面板清单）。

## 文件

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+N` | 新建文件 |
| `Ctrl+O` | 打开文件（可多选） |
| `Ctrl+S` | 保存 |
| `Ctrl+Shift+S` | 另存为 |
| `Ctrl+Alt+S` | 保存全部 |
| `Ctrl+Shift+T` | 重新打开关闭的标签（后进先出，最多 20 个） |

关闭当前标签用标签右键菜单或编辑区面板的关闭按钮（没有单独的关闭快捷键）。

「文件」菜单里还有：最近打开（菜单列出最近 5 个，内部最多记 10 个，可清除）、重命名当前文件…、删除当前文件…。

## 编辑

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做（编辑器内置） |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | 剪切 / 复制 / 粘贴 |
| `Ctrl+A` | 全选 |
| `Ctrl+F` / `Ctrl+H` | 查找 / 替换（编辑器内嵌面板） |
| `Ctrl+/` | 切换行注释（VB 用 `'`，Rust/JSON 用 `//`） |
| `Alt+↑` / `Alt+↓` | 上移行 / 下移行 |
| `Tab` / `Shift+Tab` | 增加 / 减少缩进 |
| `Ctrl+Space` | 手动唤出补全（空前缀时列出全部候选） |

## 标签

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签 |

## 跳转

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+P` | 转到文件（按文件名或完整路径模糊匹配） |
| `Ctrl+G` | 转到行 / 符号 |
| `Ctrl+Shift+P` | 命令面板 |
| `F12` | 转到定义 |
| `Shift+F12` | 查找引用 |

## 视图

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Shift+F` | 项目内搜索面板 |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 放大 / 缩小 / 重置字号 |

「查看」菜单可切换：资源管理器、代码大纲、搜索、输出、状态栏、主题、全屏。

## 运行与调试

| 快捷键 | 功能 |
| --- | --- |
| `F5` | 运行脚本 |
| `Shift+F5` | 停止脚本 |
| `Ctrl+F5` | 调试运行 |
| `F11` | 继续调试 |
| `F10` | 单步 |
| `Ctrl+F10` | 运行到光标处 |
| `F9` | 切换断点 |
| `Ctrl+Shift+F9` | 清除所有断点 |

「运行」菜单里还有：检查语法、运行参数…、暂停、设置条件断点…、添加监视…、清除所有监视。

## 对话框与输入框

| 按键 | 行为 |
| --- | --- |
| `Enter` | 等同「确定」/ 触发当前输入框的搜索 |
| `Esc` | 取消 / 关闭（搜索面板里直接收起面板） |
| 再按一次打开它的快捷键 | 例如对话框里再按 `Ctrl+P`、`Ctrl+G`、`Ctrl+Shift+P` 等于取消 |

## 鼠标操作

| 操作 | 效果 |
| --- | --- |
| 标签右键 | 关闭 / 关闭其它 / 关闭右侧 / 关闭全部 / 全部保存 / 复制路径 |
| 编辑器右键 | 撤销/重做/剪切/复制/粘贴/全选、上移/下移行、切换注释、缩进、切换断点、设置条件断点、运行到光标处、转到定义、查找引用 |
| 资源管理器条目右键 | 文件：打开 / 重命名… / 删除… / 复制路径 / 刷新；文件夹另有新建文件/新建文件夹；根目录可「从资源管理器移除」 |
| 拖动条目到文件夹 | 移动文件（不能拖进自己或子目录，目标同名会拒绝） |
| 拖动条目到标签栏 | 打开该文件 |
| 单击输出面板「第 N 行…」 | 跳到对应代码行 |
| 拖动面板标题栏 | 停靠到左/右侧或底部，布局会被保存 |
