# VB 脚本语言参考

Q-IDE 内置的解释器以 **VB6 语法子集**为目标，并带有少量 Win64 / VBA 风格的 API 类型扩展；并不意味着兼容完整 VB6 工程或 VBA。解释器用于编写小脚本，重点是「能直接调用 Win32 API」和「能在编辑器里调试」。解释器是树遍历求值（不编译成字节码），因此语法细节以 `src/interpreter/` 下的实现为准。

- 词法 / 语法：[`lexer.rs`](../src/interpreter/lexer.rs)、[`parser.rs`](../src/interpreter/parser.rs)、[`ast.rs`](../src/interpreter/ast.rs)
- 运行时：[`runtime.rs`](../src/interpreter/runtime.rs)
- Win32 调用：[`ffi.rs`](../src/interpreter/ffi.rs)、[`trampoline.rs`](../src/interpreter/trampoline.rs)
- 内置函数：[`builtins.rs`](../src/interpreter/builtins.rs)
- 调试：[`debug.rs`](../src/interpreter/debug.rs)

## 词法要点

| 规则 | 说明 |
| --- | --- |
| 大小写 | 关键字、标识符、内置函数名都**不区分大小写**（`Dim` = `dim`，`MsgBox` = `msgbox`） |
| 注释 | `'` 到行尾；`Rem` 只有在语句开头时才是注释 |
| 语句分隔 | 换行，或 `:`（`a = 1: b = 2`） |
| 续行 | 行尾 `_` 表示下一行接着写 |
| 类型后缀 | 写在**标识符**后面：`$` String、`%` Integer、`&` Long、`!` Single、`#` Double、`@` Currency。十进制数字字面量不支持后缀（`123&` 需改成先 `Dim v As Long` 再赋值）；`&HFFFF&` 这类进制字面量可以带类型后缀，后缀不影响值 |
| 字符串 | 双引号包裹，内部用 `""` 表示一个引号：`"a""b"` 等于 `a"b` |
| 数字 | 十进制、`&H` 十六进制、`&O` 八进制、带小数点或指数的浮点 |
| 字面量 | `True` / `False` / `Nothing` / `Null` / `Empty`；日期可写成 `#2024-01-31#` 或 `#2024-01-31 12:34:56#` |

## 数据类型

`Variant`（默认）、`Byte`、`Integer`、`Long`、`LongLong`、`LongPtr`、`Single`、`Double`、`Currency`、`Date`、`Boolean`、`String`、`Object`、`Any`。

- `Currency` 使用 64 位有符号定点数存储，精度为小数点后 4 位；可用 `CCur` 转换，赋值时按银行家舍入，溢出时报错误号 6。
- `Date` 是独立类型，内部以 8 字节 OLE Automation 日期序列（`Double`）存储；`CDate` 可转换日期文本/序列值，`Now`、`Date`、`Time`、`DateSerial`、`TimeSerial`、`DateAdd`、`DateValue`、`TimeValue` 和 `FileDateTime` 返回 `Date`。日期加减数值仍为 `Date`，两个日期相减为天数 `Double`；`Format`、`Year` 等仍接受数值序列，普通显示使用 ISO `yyyy-mm-dd[ hh:nn:ss]` 格式。
- 整数与 `Single` 赋值超出目标类型范围时报**错误号 6（溢出）**，不会静默截断；`Variant` / `Double` 不做范围检查。
- `Boolean` 在结构体与文件里占 4 字节（与 VB6 一致）；参与数值运算或转换（`CInt(True)`、`True + 1`）时按 VB6 的 `True = -1` 处理。

## 变量、常量与作用域

```vb
Option Explicit          ' 未声明的变量/过程在运行时与编辑器诊断里都会报错
Option Base 0            ' 数组默认下界（0 或 1）
Option Compare Binary    ' 字符串比较方式：Binary（默认）或 Text（忽略大小写）

Dim count As Long
Dim name$, items(1 To 10) As String
Const Limit As Long = 100
Public Dim Shared As Long    ' 修饰符可写在 Dim 前面
Private gHwnd As Long        ' 模块级变量也可以省略 Dim，直接写 Private x As 类型
```

模块级只有变量/常量声明时会先执行这些声明，再自动调用 `Sub Main`；有其它模块级语句时按脚本顺序执行。

`Static` 只能写在**过程内部**（跨调用保留的局部变量）：

```vb
Sub CountCalls()
    Static calls As Long
    calls = calls + 1
    Debug.Print calls
End Sub
```

- 过程只看得到**自己的局部变量 + 模块级变量**（静态作用域），不会看到调用者的局部变量。
- 没写 `Option Explicit` 时，给未声明的名字赋值会自动隐式声明为 `Variant`。
- `Dim` 按**过程**算一次：写在循环体里不会每轮重复声明（变量保留上一轮的值），写初值时初值每轮重算；同一过程里两条不同的 `Dim` 声明同名变量才算「重复声明」。

## 引入公共定义（`#Include`）

VB6/VBA 本身没有源码级 include（它们靠工程里的多个模块）；本解释器额外支持一个预处理指令，用来放常用的结构体、常量与 API 声明：

```vb
Option Explicit
#Include "Win32常用定义.vb"

Sub Main()
    Debug.Print WM_PAINT
End Sub
```

- 写在文件里任意顶层位置即可，建议放在开头；相对路径先按**当前脚本所在目录**解析，找不到时再查 **exe 同级的 `assets/`**（放程序自带的公共定义）；被包含文件里的相对路径按它自己的目录解析。
- 同一个文件只包含一次：重复写不会重复定义；循环引用、文件不存在会报错，并定位到主文件的 `#Include` 行。
- 被包含文件里的 `Type` / `Const` / `Declare` / `Sub` / `Function` 与主文件共享同一个模块作用域，可以直接使用。
- 主文件的行号（断点、编辑器诊断）保持原样；被包含文件里的错误会显示成 `文件名 第 N 行：…`，并定位到主文件的 `#Include` 行。
- 语法检查、代码补全与运行都会展开 include；代码大纲只列出当前文件里的符号（被包含文件单独打开时才有自己的大纲）。
- include 读取的是**磁盘文件**：修改被包含文件后要先保存，主文件的实时检查与运行才会用新内容；未保存的新缓冲区没有路径，相对 include 会按进程当前目录解析，建议先保存脚本。

## 过程与函数

```vb
Sub Bump(ByRef n As Long)
    n = n + 1
End Sub

Function Add(a As Long, Optional b As Long = 10, ParamArray rest()) As Long
    Dim i As Long
    For i = 0 To UBound(rest)
        a = a + rest(i)
    Next i
    Add = a + b           ' 函数名赋值即返回值
End Function

Call Bump x               ' Call 可省略：Bump x
Debug.Print Add(1)        ' 11（Optional 默认值 10）
Debug.Print Add(1, 2, 3)  ' 6（ParamArray 收集剩余实参）
```

- 参数默认 **`ByRef`**；形参声明可用 `ByVal` 按值传递，`Call Foo(ByVal value)` 也可在调用点对单个实参显式按值传递（即使形参声明为 `ByRef`）。
- 数组参数两种写法都可以：`arr() As Integer`（VB6）或 `arr As Integer()`（VB.NET 风格），进来都是与调用方共享的同一个数组。
- `Optional` 支持默认值，`ParamArray` 把剩余实参收成 0 基数组。
- `Exit Sub` / `Exit Function` / `Exit Property` 提前返回；`Return 值` 也可以（`Sub` 里不带值）。
- 递归默认最深 200 层，超出报错。

### 属性

模块级与类内都可以写 `Property Get` / `Property Let` / `Property Set`：

```vb
Dim mTotal As Long

Public Property Get Total() As Long
    Total = mTotal
End Property

Public Property Let Total(ByVal value As Long)
    mTotal = value
End Property
```

`x = 对象.Total` 走 `Get`，`对象.Total = 值` 走 `Let`，`Set 对象.Ref = 另一个对象` 走 `Set`。

## 语句与控制流

```vb
If a > 0 Then
    Debug.Print "正"
ElseIf a = 0 Then
    Debug.Print "零"
Else
    Debug.Print "负"
End If

For i = 1 To 10 Step 2
    If i = 5 Then Exit For
Next i

For Each item In items
    Debug.Print item
Next

Do While n > 0
    n = n - 1
Loop

Do
    n = n + 1
Loop Until n > 10

While n < 3
    n = n + 1
Wend

Select Case grade
    Case "A"
        Debug.Print "优"
    Case Is >= 90
        Debug.Print "90 以上"
    Case 60 To 89
        Debug.Print "及格"
    Case Else
        Debug.Print "其它"
End Select

Start:
    Debug.Print "跳转"
    If n < 3 Then GoTo Start

Stop                      ' 立即结束脚本执行
```

`Case` 支持值、`Case Is <运算符> 值`、`Case 低 To 高`，可逗号并列多个条件。

`For` 的起止值与步长都是整数时按整数精确步进（不受浮点累加误差影响，边界与 VB 一致）；
任一为小数时才用浮点循环。

## 数组

```vb
Dim a(10) As Long             ' 下界由 Option Base 决定
Dim b() As Long               ' 动态数组：先不带维度，之后用 ReDim
ReDim b(1 To 5, 1 To 3)
ReDim Preserve b(1 To 5, 1 To 5)
Erase a

Dim c = {64, 34, 25, 12}              ' 数组字面量（等价于 Array(64, 34, 25, 12)）
Dim d As Integer() = {3, 1, 2}        ' VB.NET 风格的类型后缀括号 + 初值
```

- `Lbound(a)` / `UBound(a[, 维])` 取边界。
- `ReDim Preserve` 只保留**最后一维**已有的元素，并且只能调整最后一维的大小（与 VB 一致）；
  对还没分配过的动态数组，首次 `ReDim Preserve` 也可以直接用。
- `{…}` 字面量里的元素可以是任意表达式、字符串或嵌套数组；允许尾逗号 `{1, 2,}`，`{}` 是空数组。
- 数组、记录**赋值按值复制**；作为 `ByRef` 实参（如 `Bump a(0)`）时仍共享同一份存储。
- 元素可以是记录：`Dim pts(2) As Point`、`pts(0).X = 1`。

## 记录、枚举与 With

```vb
Type Point
    X As Long
    Y As Long
    Tag As String * 8         ' 定长字符串：按空格补齐/截断，Len 仍为 8
    Items(1 To 3) As Long     ' 定长数组
End Type

Enum Color
    Red = 1
    Green
End Enum

Dim p As Point
p.X = 3
With p
    .Y = 4
End With
Debug.Print p.X + p.Y
```

- `Type` 字段支持标量、`String * n`、定长数组与嵌套记录。
- `String * n` 的 `n` 最多 65535（与 VB6 一致）；定长数组字段最多允许 1,000,000 个元素，超出在解析阶段报错。
- `Enum ... End Enum` 的成员是模块级常量；显式值可使用整数常量表达式（包括此前定义的枚举成员），`Dim c As Color` 按 `Long` 处理。
- `With` 块内用 `.成员` 访问记录、类实例或 COM 对象，也可调用 `.方法 参数` / `.方法(参数)`。

## 运算符与过程控制

- 支持 `Like`（`*`、`?`、`#`、`[字符范围]` 和 `[!字符集]`），大小写比较遵循 `Option Compare`。
- 支持 `Eqv`、`Imp` 位运算及 VB 运算符优先级。
- 支持过程内 `GoSub 标签` / `Return` 子程序返回；`Return 值` 仍保留为解释器原有扩展。

## 对象：Collection、Dictionary、Class

```vb
Dim names As New Collection
names.Add "甲"
names.Add "乙"
Debug.Print names.Count, names.Item(1)
names.Remove 1

Dim d As New Dictionary
Set d = New Dictionary
d.Add "key", 1
d("other") = 2
If d.Exists("key") Then Debug.Print d("key")
Dim k
For Each k In d.Keys
    Debug.Print k, d(k)
Next
```

```vb
Class Person
    Public Name As String
    Private mAge As Long

    Private Sub Class_Initialize()
        mAge = 0
    End Sub

    Private Sub Class_Terminate()
        Debug.Print "回收 " & Me.Name
    End Sub

    Public Property Get Age() As Long
        Age = mAge
    End Property

    Public Property Let Age(ByVal value As Long)
        mAge = value
    End Property

    Public Sub Greet()
        Debug.Print "你好，" & Me.Name & "（" & Me.Age & " 岁）"
    End Sub
End Class

Dim p As New Person
p.Name = "小明"
p.Age = 18
p.Greet
Debug.Print TypeOf p Is Person
Set p = Nothing            ' 最后一个引用消失时触发 Class_Terminate
```

- 实例是**引用语义**：赋值与传参共享同一个对象。
- `Class_Initialize` / `Class_Terminate` 分别相当于构造函数与析构。
- 类内字段可以直接写成员名或 `Me.成员`；属性要写 `Me.属性`（裸写 `Age` 会被当成未声明变量），裸赋值 `Name = v` 也不会触发同名 `Property Let`。
- 事件：`Private WithEvents m As New Clock` 订阅另一个类，`RaiseEvent 事件(实参)` 会回调订阅者的 `源类名_事件名` 方法（订阅表使用弱引用）。

## COM 自动化

Windows 脚本可以通过 ProgID 创建 Automation 对象、访问属性并调用位置参数方法：

```vb
Dim shell As Object
Set shell = CreateObject("WScript.Shell")
Debug.Print shell.ExpandEnvironmentStrings("%COMSPEC%")
Debug.Print shell.CurrentDirectory
shell.CurrentDirectory = shell.CurrentDirectory
```

`GetObject(, "ProgID")` 获取已注册到 Running Object Table 的活动对象；也可用
`GetObject("ProgID")` 作为简写。`GetObject("", "ProgID")` 创建指定 ProgID 的新对象。
`GetObject(pathname, class)` 会把 pathname 作为 OLE moniker display name 交给 Windows 绑定
（常见形式为文件路径）；当 pathname 是现存文件时，提供 class 会按其 ProgID 解析 CLSID，
并通过 `IPersistFile` 从文件加载该类的对象。单参数形式在参数含路径/moniker 标记
或脚本目录下存在同名文件时按 pathname 处理，相对文件路径按脚本目录解析。此文件加载方式要求
Windows 中已注册该 ProgID，且对应类支持从文件加载；其他 moniker 仍由系统绑定器处理。
COM 调用目前支持 `Empty`、`Null`、布尔、整数、浮点、
字符串和另一个 COM 对象作为实参/返回值；COM 方法支持 `参数名:=值` 命名实参（组件需通过
`IDispatch` 暴露形参名），可赋值的标量/字符串变量按 `ByRef VARIANT` 传递并写回；数组按值传递。
一维 `SAFEARRAY(VARIANT)` 可与 VB Variant 数组互相转换；多维、
强类型 SAFEARRAY 和 UDT 记录封送暂不支持，COM 事件接收也不支持。对象创建与调用在脚本运行线程的
COM apartment 内完成；COM 组件本身是否安装、
注册及可用取决于 Windows 环境。

## 错误处理

```vb
Sub TryDivide()
    Dim x As Long
    On Error Resume Next
    x = 1 / 0
    If Err.Number <> 0 Then
        Debug.Print Err.Number, Err.Description
        Err.Clear
    End If
    On Error GoTo 0
End Sub

Sub WithHandler()
    On Error GoTo Failed
    Err.Raise 5, "WithHandler", "自定义错误"
    Exit Sub
Failed:
    Debug.Print "出错：" & Err.Description
    Resume Next
End Sub

TryDivide
WithHandler
Debug.Print Error(5)
```

- `Err.Number` / `Err.Description` / `Err.Source`、`Err.Raise`、`Err.Clear` 与 `Error(n)` 都可用。
- `Resume` 重新执行出错语句，`Resume Next` 继续下一条，`Resume 标签` 跳到标签。
- 没有 `On Error` 时，运行时错误会中止脚本（输出面板里带行号，并自动跳到出错行）。

## 文件 I/O

```vb
Dim f As Long
f = FreeFile()
Open App.Path & "\data.txt" For Output As #f
Print #f, "第一行"
Write #f, 1, "二"
Close #f

Dim s As String
Open App.Path & "\data.txt" For Input As #1
Line Input #1, s
Debug.Print s
Close #1

Dim p As Point                                  ' 前面 Type 定义的记录
Open App.Path & "\rec.dat" For Random As #2 Len = 64
Put #2, , p        ' 记录号 1 起
Seek #2, 1
Get #2, , p
Close #2

Open App.Path & "\raw.bin" For Binary As #3
Dim v As Long
v = 123
Put #3, , v
Seek #3, 1
Get #3, , v
Lock #3, 1 To 4
Unlock #3, 1 To 4
Close #3
```

| 要点 | 说明 |
| --- | --- |
| 打开模式 | `Input` / `Output` / `Append` / `Binary` / `Random` |
| 文件号 | `As #n` 可省略，省略时自动分配最小空闲文件号（与 `FreeFile` 一致），之后用 `#1`、`#2`… 读写 |
| 相对路径 | `Open` / `Dir` / `FileLen` / `FileDateTime` / `Kill` / `FileCopy` / `MkDir` / `RmDir` / `Rename` 的相对路径都按**脚本所在目录**解析 |
| 当前目录 | `CurDir` / `ChDir` 只改脚本自己的视角，不会改编辑器进程的当前目录；`App.Path` 返回脚本目录 |
| `Get #` / `Put #` | 按变量声明类型（或表达式的动态类型）读写 1/2/4/8 字节，位置是 1 基字节偏移；目标可以是变量、数组元素或记录字段 |
| `Date` 存储 | `Date` 标量/UDT 字段按 8 字节 OLE Automation 序列读写；`Write #` 输出 `#yyyy-mm-dd[ hh:nn:ss]#`，`Input #` 可读回 |
| 定长记录 | `For Random` 下 `Get`/`Put`/`Seek`/`Loc` 的位置都是记录号，默认记录长度 128 字节；单次读写超过记录长度报错误号 59 |
| 记录整块读写 | `Put #1, , p` / `Get #1, , p` 按 `StructLayout` 的字段偏移与对齐整块读写，`Len(p)` 给出字节数 |
| 不支持 | `Variant` 与变长 `String` 的直接 `Get`/`Put` |

其余文件函数：`EOF`、`LOF`、`Seek(n)`、`Loc(n)`、`FreeFile`、`FileLen`、`FileDateTime`、`Dir`、`Kill`、`FileCopy`、`Rename`、`MkDir`、`RmDir`、`Environ`。

## 调用 Win32 API

```vb
Declare PtrSafe Function MessageBoxW Lib "user32" _
    (ByVal hWnd As LongPtr, ByVal text As String, ByVal caption As String, ByVal flags As Long) As Long

Declare PtrSafe Function GetTickCount Lib "kernel32" () As Long

Debug.Print GetTickCount()
Debug.Print MessageBoxW(0, "你好", "Q-IDE", 0)
```

`String` 形参按 W 版 API 的 `LPCWSTR` 传（本解释器只调用 W 版 API）。

```vb
Type RECT
    Left As Long
    Top As Long
    Right As Long
    Bottom As Long
End Type

Declare PtrSafe Function GetWindowRect Lib "user32" (ByVal hWnd As LongPtr, ByRef r As RECT) As Long
```

- `Declare ... Lib "库名" [Alias "..."]`，`PtrSafe` 可选；函数在运行时按名字（或别名）从 DLL 解析（W 版 API）。
- 支持 `ByRef` / `ByVal` 结构体（字段为整型、浮点、`String * n`、标量数组）；`ByVal` 结构体按 x64 ABI 传递（≤ 8 字节进寄存器，更大的传临时副本指针）。
- 参数支持最多 64 个整数、`Single`、`Double`、`Date` 标量的任意组合（`Date` 按原生 `Double` ABI 传递）；返回值可以是整数或 `Single` / `Double` / `Date`。
- 结构体字段支持整型/浮点、`String * n`、标量数组与 UDT 数组；结构体里的变长 `String` 仍不支持。
- `String * n` 在结构体与文件里占 `2n` 字节 UTF-16（本解释器只调用 W 版 API，与 VB6 的 ANSI `n` 字节不同）。

### AddressOf 回调

```vb
Declare PtrSafe Function EnumWindows Lib "user32" _
    (ByVal callback As LongPtr, ByVal lParam As LongPtr) As Long

Public Function OnWindow(ByVal hWnd As LongPtr, ByVal lParam As LongPtr) As Long
    Debug.Print hWnd
    OnWindow = 1          ' 返回 1 继续枚举
End Function

EnumWindows AddressOf OnWindow, 0
```

- 回调参数支持最多 64 个 `Byte` / `Integer` / `Long` / `Boolean` / `LongLong` / `LongPtr` / `Currency` / `Single` / `Double` / `Date` / `String` 形参及 `ByRef` UDT 形参（`Date` 按原生 `Double` ABI 传递；`ByVal String` 是 `LPCWSTR`，`ByRef String` 是 `LPWSTR *`）；返回值支持整数、`Single`、`Double` / `Date` 或 NUL 结尾的 `String`（`Sub` 视为 0）。
- 直接写在 `Declare` 实参里的 `AddressOf` 使用临时跳板，只在该次调用期间有效（`EnumWindows`、`InitOnceExecuteOnce` 等同步回调）；回调必须在脚本线程执行，来自其它线程的回调会返回默认值，不会切换线程进入解释器。
- `AddressOf` 存进 UDT 字段后再传给 `Declare`（如 `WNDCLASSW.lpfnWndProc`）会生成持久跳板，存活到脚本结束，因此 `RegisterClassW` + `CreateWindowExW` 这类窗口过程也能用。
- 数组形参不支持：原生指针本身不携带数组长度、下界与元素类型信息，无法安全还原为 VB 数组；可用 `LongPtr` 与独立长度参数表达原生接口，但解释器目前没有通用指针切片访问。脚本结束后系统再回调时会直接返回默认值，不再进入脚本（跳板上下文保留到进程结束）；旧回调也不会因后续运行复用同一栈地址而重新激活。
- x64 下句柄与指针要声明成 `LongPtr`（`Long` 只有 4 字节，放函数指针/句柄会被截断）；`Declare` 的 `As String` 参数按 UTF-16 传递，应配 W 版 API。`StrPtr(s)` 返回以 0 结尾的 UTF-16 缓冲区地址（`LongPtr`），缓冲区活到脚本结束，适合填 `lpszClassName` 这类指针字段。

### 数值与字符串转换的细节

- `CInt` / `CLng` 按银行家舍入取整，并检查目标类型范围（`CInt` 是 `Integer`、`CLng` 是 `Long`），
  越界报**错误号 6（溢出）**，非数字文本报**错误号 13（类型不匹配）**。
- `CBool` 与 `If` / `While` / `Do Until` 的条件只接受 `True` / `False`（大小写不敏感）与数字文本；
  空字符串或非数字文本报**错误号 13**（与 VB 一致，不再把任意非空字符串当成真）。
- `Str(x)` 与 VB 一致：非负数值带一个前导空格（`Str(5)` 是 `" 5"`、`Str(-5)` 是 `"-5"`），布尔值仍给 `True` / `False`。
- `Val` 支持 `&H` / `&O`（以及单独的 `&`）进制前缀，遇到无法解释的字符就停下：
  `Val("&HFF")` = 255、`Val("-12.5abc")` = -12.5。
- `Double` 按 VB6 的 **15 位有效数字**显示：`0.1 + 0.2` 打印 `0.3`、`1/3` 打印 `0.333333333333333`；
  绝对值 ≥ `1E+15` 或 < `0.001` 时改用科学计数法（`1E+15`、`1E-04`）。
- `Space(n)` / `String(n, ch)` 的 `n` 上限是 16,777,216 个字符，超出报**错误号 14（字符串空间不足）**。
- `Dictionary` 的键查找走索引表，批量插入不再退化成 O(n²)。

## 命令行运行（`qide-run`）

不开界面也能跑脚本（`cargo build` 会同时产出 `target\debug\qide-run.exe`，只链接解释器，约 3 MB）：

```powershell
qide-run demo.vb                   # 只给路径就等于 run（给文件关联用）
qide-run run  demo.vb              # 脚本输出走 stdout，诊断走 stderr
qide-run run  demo.vb --json       # 每行一个 JSON 事件，供程序 / agent 解析
qide-run check demo.vb --json      # 只做语法与语义检查，不执行
```

| 选项 | 说明 |
| --- | --- |
| `--json` | 输出 JSONL 事件（`start` / `line` / `finished` / `interrupted` / `issue` / `checked`） |
| `-q, --quiet` | 不输出脚本的 `Print` / `Debug.Print` |
| `--max-steps N` / `--max-depth N` | 覆盖步数上限（默认 20000000）与过程递归上限（默认 200） |
| `--timeout 30s` | 超时后中断脚本；也接受 `500ms`、`2m`，裸数字按秒 |
| `--include-dir DIR` | `#Include` 在脚本目录找不到时再搜这里（替代 exe 同级的 `assets/`） |
| `--arg 文本` | `Command()` 返回的内容 |
| `--ui` / `--no-ui` | 允许 / 禁止 `MsgBox`、`InputBox` 弹窗 |
| `--pause` / `--no-pause` | 结束后等待回车 |
| `--ui`、`--pause` 的默认值 | 「人直接运行」时开启，供 agent 调用时关闭，见下 |

**什么时候算「人直接运行」**：stdout 连着控制台（没有被管道接走），并且这个控制台是给自己新开的（双击启动时控制台里只有自己；从 `cmd`/PowerShell 里启动时还有宿主进程）。这种情况下默认允许弹窗、结束时停住等回车，避免双击 `.vb` 时窗口一闪就没；反之（`--json`、输出被重定向、从终端启动）默认不弹窗、不暂停。

把 `.vb` 的打开方式指向 `qide-run.exe`（命令行写 `"...\qide-run.exe" "%1"`）即可双击运行；只想检查语法时用 `qide-run check 文件`。

退出码：`0` 成功、`2` 语法或语义问题、`3` 运行时错误、`4` 超时或 Ctrl+C、`5` 读不到脚本 / 内部错误、`64` 参数用法错误。

`--json` 的结束事件带结构化错误，程序不必解析中文文本：

```json
{"type":"finished","ok":false,"kind":"runtime","number":6,"line":12,"message":"溢出"}
```

相对路径按脚本所在目录解析（与编辑器里运行一致）；控制台代码页会切到 UTF-8，`stdout` 可直接重定向到文件。

## 与编辑器的配合

| 入口 | 说明 |
| --- | --- |
| 运行（`F5`） | 在后台线程解释执行当前标签里的脚本，`Debug.Print` / `Print` 输出到输出面板 |
| 调试运行（`Ctrl+F5`） | 命中 `F9` 断点或暂停请求时停下，可看变量快照、调用栈、监视表达式 |
| 运行参数… | 内容由脚本里的 `Command()` 读取 |
| 检查语法 | 只解析不执行，错误写进输出面板 |
| 停止脚本（`Shift+F5`） | 置中断标志：解释器会在语句边界停下，`MsgBox` / `InputBox` 创建的对话框也会被关闭 |
| 语义检查 | `Option Explicit` 下的未声明变量、`ReDim` 未声明数组、未定义的过程名，作为编辑器诊断实时提示 |

运行限制：默认最多执行 20,000,000 条语句、过程嵌套 200 层（`RunOptions`），超限报错而不是卡死界面；
语法分析的嵌套上限是 96 层（防止超深嵌套把栈耗尽，正常脚本远达不到）；
递归到线程栈空间不足时同样报错（错误号 28），不会让程序崩溃。

## 已知边界与完善优先级

以下按通用 VB6/VBA 脚本里的估计使用频率排序，不代表本程序的遥测统计：

1. **类成员访问控制（已完善）**：字段默认 `Private`，方法和属性默认 `Public`；显式修饰符生效，同类成员可以访问私有成员。
2. **COM 自动化扩展（`GetObject` 文件/moniker、命名/ByRef 和一维 Variant 数组已完善）**：已支持 `CreateObject`、ROT 活动对象和 moniker `GetObject(path, class)`、Automation 属性读写与位置/命名参数调用；多维/强类型 SAFEARRAY、UDT 记录封送和 COM 事件尚不支持。
3. **日期与货币类型（基础 Date/Currency 已完善）**：`Currency` 是四位小数定点数；`Date` 是独立类型，使用 OLE Automation 序列表示，支持日期字面量、转换、日期内置函数、算术、8 字节二进制存储、Win32 Double ABI 与 COM `VT_DATE` 封送。日期文本格式化及负日期序列等仍非完整 VBA 实现。
4. **二进制文件 I/O**：`Get #` / `Put #` 不支持直接读写 `Variant` 与变长 `String`。
5. **Win32 调用 ABI（标量混合与 UDT 数组已完善）**：结构体里的变长 `String` 仍不支持；一次声明最多 64 个参数。
6. **回调边界**：最多支持 64 个整数/浮点/字符串参数，支持整数/浮点/字符串返回与 ByRef UDT 参数；数组形参不支持，且持久回调在脚本结束后不再进入解释器。
7. **接口实现限制**：支持类级 `Implements` 与 `接口名_成员名` 私有实现分派；接口变量的静态类型、编译期接口成员检查和完整 COM 类接口机制尚未实现。
8. **多文件类引用**：`Dim x As 类名` 需要类在同一个文件里先定义。
9. **模块级访问控制**：`Public` / `Private` 目前只接受语法，不会隔离模块变量的可见性。
10. **数字字面量类型后缀**：十进制数字字面量不能带后缀（`123&` 要写成 `Dim v As Long` 后赋值）；进制字面量的后缀（如 `&HFFFF&`）可以写。
- x64 下把 `HWND` / `HDC` / 函数指针等声明成 `Long` 会被截断，必须用 `LongPtr`。

## 完整示例：写一个日志文件

```vb
Option Explicit

Declare PtrSafe Function GetTickCount Lib "kernel32" () As Long

Sub WriteLog(ByVal text As String)
    Dim f As Long
    f = FreeFile()
    Open App.Path & "\run.log" For Append As #f
    Print #f, Format(Now, "yyyy-mm-dd hh:nn:ss") & " " & text
    Close #f
End Sub

Dim i As Long, total As Long
For i = 1 To 100
    total = total + i
Next i

WriteLog "合计 " & total
Debug.Print "用时（毫秒）：", GetTickCount()
MsgBox "计算完成，合计 " & total, 64, "Q-IDE"   ' 64 = vbInformation
```
