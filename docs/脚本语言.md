# VB 脚本语言参考

Q-IDE 内置的解释器实现的是 **VB6 / VBA 的一个子集**：用熟悉的 VB 语法写小脚本，重点是「能直接调用 Win32 API」和「能在编辑器里调试」。解释器是树遍历求值（不编译成字节码），因此语法细节以 `src/interpreter/` 下的实现为准。

- 词法 / 语法：[`lexer.rs`](../src/interpreter/lexer.rs)、[`parser.rs`](../src/interpreter/parser.rs)、[`ast.rs`](../src/interpreter/ast.rs)
- 运行时：[`runtime.rs`](../src/interpreter/runtime.rs)
- Win32 调用：[`ffi.rs`](../src/interpreter/ffi.rs)、[`trampoline.rs`](../src/interpreter/trampoline.rs)
- 内置函数：[`builtins.rs`](../src/interpreter/builtins.rs)
- 调试：[`debug.rs`](../src/interpreter/debug.rs)

## 词法要点

| 规则 | 说明 |
| --- | --- |
| 大小写 | 关键字、标识符、内置函数名都**不区分大小写**（`Dim` = `dim`，`MsgBox` = `msgbox`） |
| 注释 | `'` 到行尾；`Rem` 只有在语句开头时才是注释 |
| 语句分隔 | 换行，或 `:`（`a = 1: b = 2`） |
| 续行 | 行尾 `_` 表示下一行接着写 |
| 类型后缀 | 写在**标识符**后面：`$` String、`%` Integer、`&` Long、`!` Single、`#` Double（`@` = Currency 未实现）。数字字面量不支持后缀：`123&` 需改成先 `Dim v As Long` 再赋值 |
| 字符串 | 双引号包裹，内部用 `""` 表示一个引号：`"a""b"` 等于 `a"b` |
| 数字 | 十进制、`&H` 十六进制、`&O` 八进制、带小数点或指数的浮点 |
| 字面量 | `True` / `False` / `Nothing` / `Null` / `Empty` |

## 数据类型

`Variant`（默认）、`Byte`、`Integer`、`Long`、`LongLong`、`LongPtr`、`Single`、`Double`、`Boolean`、`String`、`Object`、`Any`。

- 没有 `Date` / `Currency` 类型：日期时间用 `Double` 序列值表示（`Now` 返回序列值，`Date` / `Time` 返回它的整数/小数部分，`Year` / `Format` 等直接接受序列值）。
- 整数与 `Single` 赋值超出目标类型范围时报**错误号 6（溢出）**，不会静默截断；`Variant` / `Double` 不做范围检查。
- `Boolean` 在结构体与文件里占 4 字节（与 VB6 一致）。

## 变量、常量与作用域

```vb
Option Explicit          ' 未声明的变量/过程在运行时与编辑器诊断里都会报错
Option Base 0            ' 数组默认下界（0 或 1）
Option Compare Binary    ' 字符串比较方式：Binary（默认）或 Text（忽略大小写）

Dim count As Long
Dim name$, items(1 To 10) As String
Const Limit As Long = 100
Public Dim Shared As Long    ' Public / Private / Global 只做语法接受，且必须写在 Dim 前面
```

`Static` 只能写在**过程内部**（跨调用保留的局部变量）：

```vb
Sub CountCalls()
    Static calls As Long
    calls = calls + 1
    Debug.Print calls
End Sub
```

- 过程只看得到**自己的局部变量 + 模块级变量**（静态作用域），不会看到调用者的局部变量。
- 没写 `Option Explicit` 时，给未声明的名字赋值会自动隐式声明为 `Variant`。

## 过程与函数

```vb
Sub Bump(ByRef n As Long)
    n = n + 1
End Sub

Function Add(a As Long, Optional b As Long = 10, ParamArray rest()) As Long
    Dim i As Long
    For i = 0 To UBound(rest)
        a = a + rest(i)
    Next i
    Add = a + b           ' 函数名赋值即返回值
End Function

Call Bump x               ' Call 可省略：Bump x
Debug.Print Add(1)        ' 11（Optional 默认值 10）
Debug.Print Add(1, 2, 3)  ' 6（ParamArray 收集剩余实参）
```

- 参数默认 **`ByRef`**；`ByVal` 显式按值传递。
- `Optional` 支持默认值，`ParamArray` 把剩余实参收成 0 基数组。
- `Exit Sub` / `Exit Function` / `Exit Property` 提前返回；`Return 值` 也可以（`Sub` 里不带值）。
- 递归默认最深 200 层，超出报错。

### 属性

模块级与类内都可以写 `Property Get` / `Property Let` / `Property Set`：

```vb
Dim mTotal As Long

Public Property Get Total() As Long
    Total = mTotal
End Property

Public Property Let Total(ByVal value As Long)
    mTotal = value
End Property
```

`x = 对象.Total` 走 `Get`，`对象.Total = 值` 走 `Let`，`Set 对象.Ref = 另一个对象` 走 `Set`。

## 语句与控制流

```vb
If a > 0 Then
    Debug.Print "正"
ElseIf a = 0 Then
    Debug.Print "零"
Else
    Debug.Print "负"
End If

For i = 1 To 10 Step 2
    If i = 5 Then Exit For
Next i

For Each item In items
    Debug.Print item
Next

Do While n > 0
    n = n - 1
Loop

Do
    n = n + 1
Loop Until n > 10

While n < 3
    n = n + 1
Wend

Select Case grade
    Case "A"
        Debug.Print "优"
    Case Is >= 90
        Debug.Print "90 以上"
    Case 60 To 89
        Debug.Print "及格"
    Case Else
        Debug.Print "其它"
End Select

Start:
    Debug.Print "跳转"
    If n < 3 Then GoTo Start

Stop                      ' 立即结束脚本执行
```

`Case` 支持值、`Case Is <运算符> 值`、`Case 低 To 高`，可逗号并列多个条件。

## 数组

```vb
Dim a(10) As Long             ' 下界由 Option Base 决定
Dim b() As Long               ' 动态数组：先不带维度，之后用 ReDim
ReDim b(1 To 5, 1 To 3)
ReDim Preserve b(1 To 5, 1 To 5)
Erase a
```

- `Lbound(a)` / `UBound(a[, 维])` 取边界。
- 数组、记录**赋值按值复制**；作为 `ByRef` 实参（如 `Bump a(0)`）时仍共享同一份存储。
- 元素可以是记录：`Dim pts(2) As Point`、`pts(0).X = 1`。

## 记录、枚举与 With

```vb
Type Point
    X As Long
    Y As Long
    Tag As String * 8         ' 定长字符串：按空格补齐/截断，Len 仍为 8
    Items(1 To 3) As Long     ' 定长数组
End Type

Enum Color
    Red = 1
    Green
End Enum

Dim p As Point
p.X = 3
With p
    .Y = 4
End With
Debug.Print p.X + p.Y
```

- `Type` 字段支持标量、`String * n`、定长数组与嵌套记录。
- `Enum ... End Enum` 的成员是模块级常量；`Dim c As Color` 按 `Long` 处理。
- `With` 块内用 `.成员` 访问对象。

## 对象：Collection、Dictionary、Class

```vb
Dim names As New Collection
names.Add "甲"
names.Add "乙"
Debug.Print names.Count, names.Item(1)
names.Remove 1

Dim d As New Dictionary
Set d = New Dictionary
d.Add "key", 1
d("other") = 2
If d.Exists("key") Then Debug.Print d("key")
Dim k
For Each k In d.Keys
    Debug.Print k, d(k)
Next
```

```vb
Class Person
    Public Name As String
    Private mAge As Long

    Private Sub Class_Initialize()
        mAge = 0
    End Sub

    Private Sub Class_Terminate()
        Debug.Print "回收 " & Me.Name
    End Sub

    Public Property Get Age() As Long
        Age = mAge
    End Property

    Public Property Let Age(ByVal value As Long)
        mAge = value
    End Property

    Public Sub Greet()
        Debug.Print "你好，" & Me.Name & "（" & Me.Age & " 岁）"
    End Sub
End Class

Dim p As New Person
p.Name = "小明"
p.Age = 18
p.Greet
Debug.Print TypeOf p Is Person
Set p = Nothing            ' 最后一个引用消失时触发 Class_Terminate
```

- 实例是**引用语义**：赋值与传参共享同一个对象。
- `Class_Initialize` / `Class_Terminate` 分别相当于构造函数与析构。
- 类内字段可以直接写成员名或 `Me.成员`；属性要写 `Me.属性`（裸写 `Age` 会被当成未声明变量），裸赋值 `Name = v` 也不会触发同名 `Property Let`。
- 事件：`Private WithEvents m As New Clock` 订阅另一个类，`RaiseEvent 事件(实参)` 会回调订阅者的 `源类名_事件名` 方法（订阅表使用弱引用）。

## 错误处理

```vb
Sub TryDivide()
    Dim x As Long
    On Error Resume Next
    x = 1 / 0
    If Err.Number <> 0 Then
        Debug.Print Err.Number, Err.Description
        Err.Clear
    End If
    On Error GoTo 0
End Sub

Sub WithHandler()
    On Error GoTo Failed
    Err.Raise 5, "WithHandler", "自定义错误"
    Exit Sub
Failed:
    Debug.Print "出错：" & Err.Description
    Resume Next
End Sub

TryDivide
WithHandler
Debug.Print Error(5)
```

- `Err.Number` / `Err.Description` / `Err.Source`、`Err.Raise`、`Err.Clear` 与 `Error(n)` 都可用。
- `Resume` 重新执行出错语句，`Resume Next` 继续下一条，`Resume 标签` 跳到标签。
- 没有 `On Error` 时，运行时错误会中止脚本（输出面板里带行号，并自动跳到出错行）。

## 文件 I/O

```vb
Dim f As Long
f = FreeFile()
Open App.Path & "\data.txt" For Output As #f
Print #f, "第一行"
Write #f, 1, "二"
Close #f

Dim s As String
Open App.Path & "\data.txt" For Input As #1
Line Input #1, s
Debug.Print s
Close #1

Dim p As Point                                  ' 前面 Type 定义的记录
Open App.Path & "\rec.dat" For Random As #2 Len = 64
Put #2, , p        ' 记录号 1 起
Seek #2, 1
Get #2, , p
Close #2

Open App.Path & "\raw.bin" For Binary As #3
Dim v As Long
v = 123
Put #3, , v
Seek #3, 1
Get #3, , v
Lock #3, 1 To 4
Unlock #3, 1 To 4
Close #3
```

| 要点 | 说明 |
| --- | --- |
| 打开模式 | `Input` / `Output` / `Append` / `Binary` / `Random` |
| 文件号 | `As #n` 可省略，省略时自动分配最小空闲文件号（与 `FreeFile` 一致），之后用 `#1`、`#2`… 读写 |
| 相对路径 | `Open` / `Dir` / `FileLen` / `FileDateTime` / `Kill` / `FileCopy` / `MkDir` / `RmDir` / `Rename` 的相对路径都按**脚本所在目录**解析 |
| 当前目录 | `CurDir` / `ChDir` 只改脚本自己的视角，不会改编辑器进程的当前目录；`App.Path` 返回脚本目录 |
| `Get #` / `Put #` | 按变量声明类型（或表达式的动态类型）读写 1/2/4/8 字节，位置是 1 基字节偏移；目标可以是变量、数组元素或记录字段 |
| 定长记录 | `For Random` 下 `Get`/`Put`/`Seek`/`Loc` 的位置都是记录号，默认记录长度 128 字节；单次读写超过记录长度报错误号 59 |
| 记录整块读写 | `Put #1, , p` / `Get #1, , p` 按 `StructLayout` 的字段偏移与对齐整块读写，`Len(p)` 给出字节数 |
| 不支持 | `Variant` 与变长 `String` 的直接 `Get`/`Put` |

其余文件函数：`EOF`、`LOF`、`Seek(n)`、`Loc(n)`、`FreeFile`、`FileLen`、`FileDateTime`、`Dir`、`Kill`、`FileCopy`、`Rename`、`MkDir`、`RmDir`、`Environ`。

## 调用 Win32 API

```vb
Declare PtrSafe Function MessageBoxW Lib "user32" _
    (ByVal hWnd As LongPtr, ByVal text As String, ByVal caption As String, ByVal flags As Long) As Long

Declare PtrSafe Function GetTickCount Lib "kernel32" () As Long

Debug.Print GetTickCount()
Debug.Print MessageBoxW(0, "你好", "Q-IDE", 0)
```

`String` 形参按 W 版 API 的 `LPCWSTR` 传（本解释器只调用 W 版 API）。

```vb
Type RECT
    Left As Long
    Top As Long
    Right As Long
    Bottom As Long
End Type

Declare PtrSafe Function GetWindowRect Lib "user32" (ByVal hWnd As LongPtr, ByRef r As RECT) As Long
```

- `Declare ... Lib "库名" [Alias "..."]`，`PtrSafe` 可选；函数在运行时按名字（或别名）从 DLL 解析（W 版 API）。
- 支持 `ByRef` / `ByVal` 结构体（字段为整型、浮点、`String * n`、标量数组）；`ByVal` 结构体按 x64 ABI 传递（≤ 8 字节进寄存器，更大的传临时副本指针）。
- 参数支持整数、全 `Double`、全 `Single`，以及最多 4 个参数的整数/`Double` 混合调用；返回值可以是整数或 `Single` / `Double`。
- **不支持**：`Single` 与 `Double` 混用、超过 4 个参数的混合浮点调用、结构体里的变长 `String` 与 UDT 数组字段。
- `String * n` 在结构体与文件里占 `2n` 字节 UTF-16（本解释器只调用 W 版 API，与 VB6 的 ANSI `n` 字节不同）。

### AddressOf 回调

```vb
Declare PtrSafe Function EnumWindows Lib "user32" _
    (ByVal callback As LongPtr, ByVal lParam As LongPtr) As Long

Public Function OnWindow(ByVal hWnd As LongPtr, ByVal lParam As LongPtr) As Long
    Debug.Print hWnd
    OnWindow = 1          ' 返回 1 继续枚举
End Function

EnumWindows AddressOf OnWindow, 0
```

- 回调参数支持最多 3 个 `Byte` / `Integer` / `Long` / `Boolean` / `LongLong` / `LongPtr` / `Single` / `Double` / `String` 形参（`ByVal String` 是 `LPCWSTR`，`ByRef` 是 `LPWSTR *`），返回值可以是整数类型（`Sub` 视为 0）。
- 跳板只在这次 `Declare` 调用期间有效，因此只适用于「调用期间同步回调」的 API（`EnumWindows`、`InitOnceExecuteOnce` 等）；把指针存起来以后再回调的 API 不能用这种方式。

## 与编辑器的配合

| 入口 | 说明 |
| --- | --- |
| 运行（`F5`） | 在后台线程解释执行当前标签里的脚本，`Debug.Print` / `Print` 输出到输出面板 |
| 调试运行（`Ctrl+F5`） | 命中 `F9` 断点或暂停请求时停下，可看变量快照、调用栈、监视表达式 |
| 运行参数… | 内容由脚本里的 `Command()` 读取 |
| 检查语法 | 只解析不执行，错误写进输出面板 |
| 停止脚本（`Shift+F5`） | 置中断标志：解释器会在语句边界停下，`MsgBox` / `InputBox` 创建的对话框也会被关闭 |
| 语义检查 | `Option Explicit` 下的未声明变量、`ReDim` 未声明数组、未定义的过程名，作为编辑器诊断实时提示 |

运行限制：默认最多执行 20,000,000 条语句、过程嵌套 200 层（`RunOptions`），超限报错而不是卡死界面。

## 已知边界

- 不支持 COM 自动化（`CreateObject` / `GetObject`），也没有 `Implements`。
- 没有 `Currency` 类型，`Date` 只是 `Double` 序列值。
- 数字字面量不能带类型后缀（`123&` 要写成 `Dim v As Long` 后赋值）。
- `Public` / `Private` 只做语法接受，类的成员都从外部可见。
- `Dim x As 类名` 需要类在同一个文件里先定义。
- 结构体里的变长 `String`、UDT 数组字段不能用于 Win32 调用。
- `AddressOf` 仅支持同步回调（见上）。

## 完整示例：写一个日志文件

```vb
Option Explicit

Declare PtrSafe Function GetTickCount Lib "kernel32" () As Long

Sub WriteLog(ByVal text As String)
    Dim f As Long
    f = FreeFile()
    Open App.Path & "\run.log" For Append As #f
    Print #f, Format(Now, "yyyy-mm-dd hh:nn:ss") & " " & text
    Close #f
End Sub

Dim i As Long, total As Long
For i = 1 To 100
    total = total + i
Next i

WriteLog "合计 " & total
Debug.Print "用时（毫秒）：", GetTickCount()
MsgBox "计算完成，合计 " & total, 64, "Q-IDE"   ' 64 = vbInformation
```
