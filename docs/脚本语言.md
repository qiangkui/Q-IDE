# VB 脚本语言参考

Q-IDE 内置的解释器以 **VB6 语法子集**为目标，并带有少量 Win64 / VBA 风格的 API 类型扩展；并不意味着兼容完整 VB6 工程或 VBA。解释器用于编写小脚本，重点是「能直接调用 Win32 API」和「能在编辑器里调试」。解释器是树遍历求值（不编译成字节码），因此语法细节以 `src/interpreter/` 下的实现为准。

- 词法 / 语法：[`lexer.rs`](../src/interpreter/lexer.rs)、[`parser.rs`](../src/interpreter/parser.rs)、[`ast.rs`](../src/interpreter/ast.rs)
- 运行时：[`runtime/`](../src/interpreter/runtime)
- Win32 调用：[`ffi.rs`](../src/interpreter/ffi.rs)、[`trampoline.rs`](../src/interpreter/trampoline.rs)
- 内置函数：[`builtins/`](../src/interpreter/builtins)
- 调试：[`debug.rs`](../src/interpreter/debug.rs)

## 词法要点

| 规则 | 说明 |
| --- | --- |
| 大小写 | 关键字、标识符、内置函数名都**不区分大小写**（`Dim` = `dim`，`MsgBox` = `msgbox`） |
| 注释 | `'` 到行尾；`Rem` 只有在语句开头时才是注释 |
| 语句分隔 | 换行，或 `:`（`a = 1: b = 2`） |
| 续行 | 行尾 `_` 表示下一行接着写 |
| 类型后缀 | 写在**标识符**后面：`$` String、`%` Integer、`&` Long、`!` Single、`#` Double、`@` Currency；数字字面量也可以带（`123&` 是 Long、`45%` 是 Integer、`1.5!` 是 Single、`2#` 是 Double、`3.25@` 是 Currency），进制字面量同样支持（`&HFFFF&`） |
| 字符串 | 双引号包裹，内部用 `""` 表示一个引号：`"a""b"` 等于 `a"b` |
| 数字 | 十进制、`&H` 十六进制、`&O` 八进制、带小数点或指数的浮点。**进制字面量按「装得下它的最小整数宽度」取补码**（VB6 实测）：`&HFFFF` 是 Integer 的 -1、`&H8000` 是 -32768、`&O177777` 是 -1；超过 4 位十六进制（或带 `&` 后缀）按 Long，`&HFFFFFFFF` 与 `&HFFFFFFFF&` 都是 -1、`&HFFFF&` 是 65535 |
| 字面量 | `True` / `False` / `Nothing` / `Null` / `Empty`；日期可写成 `#2024-01-31#` 或 `#2024-01-31 12:34:56#` |

## 数据类型

`Variant`（默认）、`Byte`、`Integer`、`Long`、`LongLong`、`LongPtr`、`Single`、`Double`、`Currency`、`Date`、`Boolean`、`String`、`Object`、`Any`。

- `Currency` 使用 64 位有符号定点数存储，精度为小数点后 4 位；可用 `CCur` 转换，赋值时按银行家舍入，溢出时报错误号 6。
- `Date` 是独立类型，内部以 8 字节 OLE Automation 日期序列（`Double`）存储；`CDate` 可转换日期文本/序列值，`Now`、`Date`、`Time`、`DateSerial`、`TimeSerial`、`DateAdd`、`DateValue`、`TimeValue` 和 `FileDateTime` 返回 `Date`。日期加减数值仍为 `Date`，两个日期相减为天数 `Double`；`Format`、`Year`、`DatePart` 等仍接受数值序列，普通显示按 VB6 的 `General Date`（`2024/2/29[ 13:05:06]`）。
- 整数与 `Single` 赋值超出目标类型范围时报**错误号 6（溢出）**，不会静默截断；`Variant` / `Double` 不做范围检查。
- `Boolean` 在结构体与文件里占 4 字节（与 VB6 一致）；参与数值运算或转换（`CInt(True)`、`True + 1`）时按 VB6 的 `True = -1` 处理。
- `Nothing` 是**独立的值**，不是 `Empty`（本机 VB6 逐条实测，黄金用例 `nothing_semantics` 覆盖）：
  `VarType(Nothing)` 是 9、`TypeName(Nothing)` 是 `Nothing`、`IsObject(Nothing)` 为真、`IsEmpty(Nothing)` / `IsNull(Nothing)` 为假、
  `Nothing Is Nothing` 为真、`ObjPtr(Nothing)` 是 0；声明成对象的变量初值就是它（`Dim o As Object` 之后 `TypeName(o)` 是 `Nothing`）。
  `Set x = Nothing` 之后 `x` 仍是对象（`IsEmpty(x)` 是 `False`）；对未赋值的对象取成员报 91，`If Nothing Then` 报 91，
  而 `Dim v`（`Empty`）写 `v Is Nothing` 报 **424**。把 `Nothing` 当普通值用（`CStr(Nothing)`、`Len(Nothing)`、`Nothing & ""`）在 VB6 里是**编译期**错误，
  QIDE 宽松处理为空串。

## 变量、常量与作用域

```vb
Option Explicit          ' 未声明的变量/过程在运行时与编辑器诊断里都会报错
Option Base 0            ' 数组默认下界（0 或 1）
Option Compare Binary    ' 字符串比较方式：Binary（默认）或 Text（忽略大小写）

Dim count As Long
Dim name$, items(1 To 10) As String
Const Limit As Long = 100
Public Dim Shared As Long    ' 修饰符可写在 Dim 前面
Private gHwnd As Long        ' 模块级变量也可以省略 Dim，直接写 Private x As 类型
```

模块级只有变量/常量声明时会先执行这些声明，再自动调用 `Sub Main`；有其它模块级语句时按脚本顺序执行。

`Static` 只能写在**过程内部**（跨调用保留的局部变量）：

```vb
Sub CountCalls()
    Static calls As Long
    calls = calls + 1
    Debug.Print calls
End Sub
```

- 过程只看得到**自己的局部变量 + 模块级变量**（静态作用域），不会看到调用者的局部变量。
- 没写 `Option Explicit` 时，给未声明的名字赋值会自动隐式声明为 `Variant`。
- `Dim` 按**过程**算一次：写在循环体里不会每轮重复声明（变量保留上一轮的值），写初值时初值每轮重算；同一过程里两条不同的 `Dim` 声明同名变量才算「重复声明」。

`DefInt` / `DefStr` 这类声明写在模块级（VB6 也只允许写在过程声明之前），决定**隐式变量**的类型：

```vb
DefInt A-Z          ' 以 A-Z 开头的隐式变量是 Integer
DefStr S            ' 后写的范围覆盖先写的：以 S 开头的是 String

A = 40000           ' 运行时错误 6（溢出，Integer 装不下）
D = "text"          ' 运行时错误 13（类型不匹配）
Sx = 12             ' 隐式变量 Sx 是 String，值是 "12"
```

`DefBool` / `DefByte` / `DefCur` / `DefDate` / `DefDbl` / `DefInt` / `DefLng`（含 `DefLngLng`、`DefLngPtr`）/ `DefObj` / `DefSng` / `DefStr` / `DefVar` 都支持，可写多段（`DefInt A-C, X`）；`DefDec` 没有对应的变体类型，按 `Variant` 处理。


## 引入公共定义（`#Include`）

VB6/VBA 本身没有源码级 include（它们靠工程里的多个模块）；本解释器额外支持一个预处理指令，用来放常用的结构体、常量与 API 声明：

```vb
Option Explicit
#Include "Win32常用定义.vb"

Sub Main()
    Debug.Print WM_PAINT
End Sub
```

- 写在文件里任意顶层位置即可，建议放在开头；相对路径先按**当前脚本所在目录**解析，找不到时再查 **exe 同级的 `assets/`**（放程序自带的公共定义）；被包含文件里的相对路径按它自己的目录解析。
- 同一个文件只包含一次：重复写不会重复定义；循环引用、文件不存在会报错，并定位到主文件的 `#Include` 行。
- 被包含文件里的 `Type` / `Const` / `Declare` / `Sub` / `Function` 与主文件共享同一个模块作用域，可以直接使用。
- 主文件的行号（断点、编辑器诊断）保持原样；被包含文件里的错误会显示成 `文件名 第 N 行：…`，并定位到主文件的 `#Include` 行。
- 语法检查、代码补全与运行都会展开 include；代码大纲只列出当前文件里的符号（被包含文件单独打开时才有自己的大纲）。
- include 读取的是**磁盘文件**：修改被包含文件后要先保存，主文件的实时检查与运行才会用新内容；未保存的新缓冲区没有路径，相对 include 会按进程当前目录解析，建议先保存脚本。

## 过程与函数

```vb
Sub Bump(ByRef n As Long)
    n = n + 1
End Sub

Function Add(a As Long, Optional b As Long = 10, ParamArray rest()) As Long
    Dim i As Long
    For i = 0 To UBound(rest)
        a = a + rest(i)
    Next i
    Add = a + b           ' 函数名赋值即返回值
End Function

Call Bump x               ' Call 可省略：Bump x
Debug.Print Add(1)        ' 11（Optional 默认值 10）
Debug.Print Add(1, 2, 3)  ' 6（ParamArray 收集剩余实参）
```

- 参数默认 **`ByRef`**；形参声明可用 `ByVal` 按值传递，`Call Foo(ByVal value)` 也可在调用点对单个实参显式按值传递（即使形参声明为 `ByRef`）。
- 数组参数两种写法都可以：`arr() As Integer`（VB6）或 `arr As Integer()`（VB.NET 风格），进来都是与调用方共享的同一个数组。
- `Optional` 支持默认值，`ParamArray` 把剩余实参收成 0 基数组。
- **省略实参**：`F a, , c` / `F(a, , c)` 里空出来的位置对应可选形参（本机 VB6 实测）。
  省略的 `Variant` 可选形参（没有默认值）`IsMissing` 为真；带默认值的可选参数按默认值绑定、
  `IsMissing` 是 `False`；省略**必填**形参报 449（VB6 里这是编译错误「参数不可选」，解释器只能报运行时错）。
  QIDE 比 VB6 宽一点：末尾省略（`F(1, )`）和无括号形式（`S 1,`）也接受，VB6 这两个位置是语法错误。
- `Exit Sub` / `Exit Function` / `Exit Property` 提前返回；`Return 值` 也可以（`Sub` 里不带值）。
- 递归默认最深 200 层，超出报错。
- `Static Sub` / `Static Function`（可带 `Public` / `Private`）：过程里的**所有**局部变量（含隐式变量）都跨调用保留，与逐条写 `Static` 等价——本机 VB6 实测 `Dim` 与隐式变量都保留。

```vb
Static Sub Counter()
    Dim n As Long
    n = n + 1
    m = n * 10          ' 隐式变量同样是静态的
    Debug.Print n; "-"; m
End Sub
Counter                 ' 1-10
Counter                 ' 2-20
```

### 属性

模块级与类内都可以写 `Property Get` / `Property Let` / `Property Set`：

```vb
Dim mTotal As Long

Public Property Get Total() As Long
    Total = mTotal
End Property

Public Property Let Total(ByVal value As Long)
    mTotal = value
End Property
```

`x = 对象.Total` 走 `Get`，`对象.Total = 值` 走 `Let`，`Set 对象.Ref = 另一个对象` 走 `Set`。

## 语句与控制流

```vb
If a > 0 Then
    Debug.Print "正"
ElseIf a = 0 Then
    Debug.Print "零"
Else
    Debug.Print "负"
End If

For i = 1 To 10 Step 2
    If i = 5 Then Exit For
Next i

For Each item In items
    Debug.Print item
Next

Do While n > 0
    n = n - 1
Loop

Do
    n = n + 1
Loop Until n > 10

While n < 3
    n = n + 1
Wend

Select Case grade
    Case "A"
        Debug.Print "优"
    Case Is >= 90
        Debug.Print "90 以上"
    Case 60 To 89
        Debug.Print "及格"
    Case Else
        Debug.Print "其它"
End Select

Start:
    Debug.Print "跳转"
    If n < 3 Then GoTo Start

Stop                      ' 立即结束脚本执行
```

`Case` 支持值、`Case Is <运算符> 值`、`Case 低 To 高`，可逗号并列多个条件。

语句级调用可以不带括号（`Bump x`、`MsgBox "hi", 64`），也可以用 `Call`。
`obj.Method(实参).属性` 这种「先调用、再读属性」的整条写在语句里也可以（VB6 同样接受）：
求值后结果丢掉，例如 `rs.Fields("id").Value`。纯字段读取（`p.X`）VB6 会报「缺少子程序、函数或属性」，
QIDE 宽容地按「读出来再丢掉」处理。

`For` 的起止值与步长都是整数时按整数精确步进（不受浮点累加误差影响，边界与 VB 一致）；
任一为小数时才用浮点循环。循环正常结束后计数器停在**第一个不满足条件的值**（`For i = 1 To 4` 之后 `i` 是 5、
`For i = 10 To 1 Step -3` 之后是 -2），`Exit For` 不改变计数器——与 VB6 一致。
计数器声明成 `Integer` / `Long` / `Byte` 时，`Next` 里的自增超出该类型范围会报**错误号 6（溢出）**
（`For i As Integer = 32767 To 32767` 会执行一次循环体后报错，本机 VB6 实测）。

字符串对齐与文件复位这两组语句也支持：

```vb
Dim s As String
s = "abc"
LSet s = "x"              ' 左对齐："x  "（长度取变量当前长度）
RSet s = "x"              ' 右对齐："  x"
s = "abc"
LSet s = "wxyzuvw"        ' 超出就截掉右侧："wxy"
s = ""
LSet s = "ab"             ' 当前是空串就还是空串（不会撑长）

Reset                     ' 关闭所有已打开的文件（等价于不带参数的 Close）
```

`LSet` / `RSet` 只对字符串变量有效（`Variant` 里装着字符串也行，数字先转成文本）；对其它类型 VB6 是编译错误，
QIDE 退化成一条明确的运行时错误。

`Attribute VB_Name = "模块1"` 这类属性行（每个 VB6 的 `.bas` / `.cls` 文件第一行都是它）会被**整行跳过**，
所以从 VB6 工程里拷出来的源码不用手工删这两行。`Attribute 成员.VB_UserMemId = 0` 目前只是被忽略，**不会**
因此产生默认成员（见文末「已知边界」）。

`Debug.Assert 条件`：条件表达式会解析（写错了照样报语法错误），但**不会求值**——VB6 编译成 exe 后这句
是空操作（本机实测 `Debug.Assert 1 = 2` 之后的语句照常执行），QIDE 与编译后的行为一致。


## 数组

```vb
Dim a(10) As Long             ' 下界由 Option Base 决定
Dim b() As Long               ' 动态数组：先不带维度，之后用 ReDim
ReDim b(1 To 5, 1 To 3)
ReDim Preserve b(1 To 5, 1 To 5)
Erase a

Dim c = {64, 34, 25, 12}              ' 数组字面量（等价于 Array(64, 34, 25, 12)）
Dim d As Integer() = {3, 1, 2}        ' VB.NET 风格的类型后缀括号 + 初值
```

- `Lbound(a)` / `UBound(a[, 维])` 取边界。
- `ReDim Preserve` 只保留**最后一维**已有的元素，并且只能调整最后一维的大小（与 VB 一致）；
  对还没分配过的动态数组，首次 `ReDim Preserve` 也可以直接用。
- `{…}` 字面量里的元素可以是任意表达式、字符串或嵌套数组；允许尾逗号 `{1, 2,}`，`{}` 是空数组。
- 数组、记录**赋值按值复制**；作为 `ByRef` 实参（如 `Bump a(0)`）时仍共享同一份存储。
- 元素可以是记录：`Dim pts(2) As Point`、`pts(0).X = 1`。

## 记录、枚举与 With

```vb
Type Point
    X As Long
    Y As Long
    Tag As String * 8         ' 定长字符串：按空格补齐/截断，Len 仍为 8
    Items(1 To 3) As Long     ' 定长数组
End Type

Enum Color
    Red = 1
    Green
End Enum

Dim p As Point
p.X = 3
With p
    .Y = 4
End With
Debug.Print p.X + p.Y
```

- `Type` 字段支持标量、`String * n`、定长数组与嵌套记录。
- `String * n` 的 `n` 最多 65535（与 VB6 一致）；定长数组字段最多允许 1,000,000 个元素，超出在解析阶段报错。
- `Enum ... End Enum` 的成员是模块级常量；显式值可使用整数常量表达式（包括此前定义的枚举成员），`Dim c As Color` 按 `Long` 处理。
- `With` 块内用 `.成员` 访问记录、类实例或 COM 对象，也可调用 `.方法 参数` / `.方法(参数)`。
- `With` 里的赋值和普通赋值同义：`.X = 10` 走 `Property Let`（或字段），`Set .X = 对象` 走 `Property Set`；
  链式也一样——`.Inner.Value = 31`、`.Fields("id").Value = 1`、`.Kiddie(2).Value = 33` 都先读/调用中间层，
  再在返回的对象上赋值（本机 VB6 实测，见 `interpreter_tests` 的 `with_assigns_through_property_let_and_chained_members`）。

## 运算符与过程控制

- 支持 `Like`（`*`、`?`、`#`、`[字符范围]` 和 `[!字符集]`），大小写比较遵循 `Option Compare`。
- 所有二元运算符（**包括 `^`**）左结合：`2 ^ 3 ^ 2` 是 `(2 ^ 3) ^ 2` = 64；`-2 ^ 2` 是 `-(2 ^ 2)` = -4。
- 支持 `Eqv`、`Imp` 位运算及 VB 运算符优先级。
- `Null` 参与算术（`+ - * / \ Mod ^`）或比较（`= <> < > <= >= Like`）时结果仍是 `Null`；
  但 `&` 把 `Null` 当空串（`"[" & Null & "]"` 是 `"[]"`）。这与 VB6 一致（本机 VB6 实测）。
- 支持过程内 `GoSub 标签` / `Return` 子程序返回；`Return 值` 仍保留为解释器原有扩展。

## 输出格式（与 VB6 的差异）

`Debug.Print` / `Print #` 直接输出数值文本，**不加 VB6 那对「符号位空格 + 尾随空格」**
（VB6 的 `Debug.Print 5` 是 `" 5 "`，QIDE 是 `"5"`；逗号打印区按已写列数计算，因此列位置也会有细微差别）。
同理 `Str(0.5)` 是 `" .5"`（去前导零）而 `CStr(0.5)` 是 `"0.5"`，这两条都与 VB6 一致；
分号续行与逗号 14 列分区的语义不变。黄金脚本测试在比对前会折叠空白，只校验内容与换行。

日期按 VB6（中文区域）的 `General Date` 显示：有日期有时间的写 `2024/2/29 13:05:06`，只有日期的写
`2024/2/29`，只有时间的写 `0:00:00`（月、日、时不补零）。`Format` 的日期命名格式同样取 VB6 中文区域的
写法（`Short Date` = `2024/2/29`、`Medium Date` = `24-02-29`、`Long Date` = `2024年2月29日`、
`Medium Time` = `01:05 下午`）；需要固定写法时用自定义格式（如 `Format(d, "yyyy-mm-dd")`）。

## 对象：Collection、Dictionary、Class

```vb
Dim names As New Collection
names.Add "甲"
names.Add "乙"
Debug.Print names.Count, names.Item(1)
Debug.Print names(1)      ' 默认成员就是 Item：`c(1)` / `c("键")` 都能用（与 VB6 一致）
names.Remove 1

Dim d As New Dictionary
Set d = New Dictionary
d.Add "key", 1
d("other") = 2
If d.Exists("key") Then Debug.Print d("key")
Dim k
' `For Each` 遍历字典得到的是「键」，按插入顺序（与 VB6 的 Scripting.Dictionary 一致）
For Each k In d
    Debug.Print k, d(k)
Next
```

```vb
Class Person
    Public Name As String
    Private mAge As Long

    Private Sub Class_Initialize()
        mAge = 0
    End Sub

    Private Sub Class_Terminate()
        Debug.Print "回收 " & Me.Name
    End Sub

    Public Property Get Age() As Long
        Age = mAge
    End Property

    Public Property Let Age(ByVal value As Long)
        mAge = value
    End Property

    Public Sub Greet()
        Debug.Print "你好，" & Me.Name & "（" & Me.Age & " 岁）"
    End Sub
End Class

Dim p As New Person
p.Name = "小明"
p.Age = 18
p.Greet
Debug.Print TypeOf p Is Person
Set p = Nothing            ' 最后一个引用消失时触发 Class_Terminate
```

- 实例是**引用语义**：赋值与传参共享同一个对象。
- `Class_Initialize` / `Class_Terminate` 分别相当于构造函数与析构。
- 类内字段可以直接写成员名或 `Me.成员`；属性要写 `Me.属性`（裸写 `Age` 会被当成未声明变量），裸赋值 `Name = v` 也不会触发同名 `Property Let`。
- 事件：`Private WithEvents m As New Clock` 订阅另一个类，`RaiseEvent 事件(实参)` 会回调订阅者的 `源类名_事件名` 方法（订阅表使用弱引用）。
- 接口：`Implements 接口类` 之后，接口的每个公开成员都要在同名类里以私有过程 `接口名_成员名` 实现。实时检查会报出漏写的成员、写了接口没有的 `接口名_xxx`，以及声明形式或签名与接口成员不一致的实现。签名规则按本机 VB6 实测：过程形式（`Sub` / `Function` / `Property Get|Let|Set`）、参数个数、每个参数的类型、`ByRef`/`ByVal`、数组形式、`Optional` 与默认值、返回类型都必须一致；**参数名可以不同**。`Property Get|Let|Set` 三种访问器在接口变量上都正常分派（`Set h.Payload = t`、`h.Title = "x"`、读回都走实现类的私有访问器，已按本机 VB6 实测对齐）。

## COM 自动化

Windows 脚本可以通过 ProgID 创建 Automation 对象、访问属性并调用位置参数方法：

```vb
Dim shell As Object
Set shell = CreateObject("WScript.Shell")
Debug.Print shell.ExpandEnvironmentStrings("%COMSPEC%")
Debug.Print shell.CurrentDirectory
shell.CurrentDirectory = shell.CurrentDirectory
```

`GetObject(, "ProgID")` 获取已注册到 Running Object Table 的活动对象；
`GetObject("", "ProgID")` 创建指定 ProgID 的新对象。**单参数 `GetObject(x)` 一律把 x 当
路径/moniker**（与 VB6 实测一致，`GetObject("ProgID")` 不是取活动对象的简写）：现存文件按
OLE 文档加载、相对路径按脚本目录解析，路径缺失或不是 OLE 文档报 432，空字符串报 5，
不像路径的裸名字交给 moniker 解析（语法错误按原 HRESULT 报 -2147221020）。
`GetObject(pathname, class)` 会把 pathname 作为 OLE moniker display name 交给 Windows 绑定
（常见形式为文件路径）；当 pathname 是现存文件时，按其 ProgID 解析 CLSID 并通过
`IPersistFile` 从文件加载该类的对象（先解析类名，缺类报 429，文件不对报 432）。
此文件加载方式要求
Windows 中已注册该 ProgID，且对应类支持从文件加载；其他 moniker 仍由系统绑定器处理。
COM 调用目前支持 `Empty`、`Null`、布尔、整数、浮点、
字符串和另一个 COM 对象作为实参/返回值；COM 方法支持 `参数名:=值` 命名实参（组件需通过
`IDispatch` 暴露形参名），可赋值的标量/字符串变量按 `ByRef VARIANT` 传递并写回；数组按值传递。
一维 `SAFEARRAY(VARIANT)` 可与 VB Variant 数组互相转换；多维、强类型 SAFEARRAY 已支持（见下文），
**UDT 记录不能封送**——VB6 自己也只允许「公共对象模块里的 UDT」与 Variant 互转（标准模块里的 `Type`
传给晚期绑定调用是编译错误，本机实测），QIDE 的 UDT 没有类型库，传进 COM 时会给明确报错。对象创建与调用在脚本运行线程的
COM apartment 内完成；COM 组件本身是否安装、
注册及可用取决于 Windows 环境。

**`WithEvents`（COM 事件）**：`Dim WithEvents conn As Object` 声明的变量在 `Set` 到这个对象时
自动挂接它的连接点，处理过程名是 `变量_事件`（与 VB6 一致）：

```vb
Dim WithEvents connection As Object
Dim attempts As Long

Sub connection_WillConnect(ByVal connectionString As Variant, ByVal userID As Variant, _
        ByVal password As Variant, ByVal options As Long, ByVal status As Long, ByVal target As Object)
    attempts = attempts + 1
End Sub

Set connection = CreateObject("ADODB.Connection")
On Error Resume Next
connection.Open "Provider=NoSuchProvider;"   ' 先触发 WillConnect，再报 3706
Debug.Print attempts                          ' 1
```

事件名按源接口的类型信息解析 dispid：服务器支持 `IProvideClassInfo` 就用它，否则按接口 IID 查注册表
（ADODB 走这条路）。回调只把事件**排队**，解释器在**下一条语句**开头、以及 **`DoEvents`** 时把排队的事件
分派给处理过程——所以不会在 COM 回调里重入解释器；`DoEvents` 是同步的（VB6 的 `DoEvents` 就是在消息循环里
执行事件），返回时事件已经处理完。参数按 `ByVal` 传（对象实参可以收到 `Object`），处理过程参数少于事件实参时
多余的丢掉；事件处理过程里再触发的 COM 事件要等下一次语句边界（`pumping_events` 防递归）。
没写任何 `变量_事件` 处理过程的 `WithEvents` 变量不会挂接。声明位置支持模块级变量和类字段，
类字段的事件处理过程写在类里（用 `Me.字段` 或实例的局部变量访问实例数据）；`WithEvents` 只能用于
`As Object` 的变量，QIDE 不做早期绑定校验。

```vb
' 类 CWatcher 里
Private WithEvents mConn As Object

Public Sub Watch(ByVal conn As Object)
    Set mConn = conn
End Sub

Private Sub mConn_WillConnect(ByVal connectionString As Variant, ByVal userID As Variant, _
        ByVal password As Variant, ByVal options As Long, ByVal status As Long, ByVal target As Object)
    mHits = mHits + 1
End Sub
```


**数组封送**：任意维数的 `SAFEARRAY` 都能与脚本数组互转（各维下界、长度原样保留，`LBound`/`UBound`
照常可用），元素类型跟着数组的声明类型走：`Long()` 传出去是 `VT_ARRAY|VT_I4`、`String()` 是 `VT_BSTR`、
`Byte()`/`Integer()`/`Single()`/`Double()`/`Boolean()`/`Date()`/`Currency()` 各自对应，`Variant()` 是
`VT_ARRAY|VT_VARIANT`。本机 VB6 实测（`Scripting.Dictionary` 往返）：`VarType` 依次是 8195 / 8200 /
8209 / 8194 / 8196 / 8197 / 8203 / 8199 / 8198 / 8204，QIDE 逐条一致。UDT 数组仍不能封送。

**参数化属性与默认成员**：成员名后面接实参时先按属性取（`DISPATCH_PROPERTYGET`）、失败再按方法调
（`DISPATCH_METHOD`），所以 `d.Item("k")` 这类参数化属性和 `d.Add "k", "v"` 这类方法都能用；
对象后面直接接实参走**默认成员**（`DISPID_VALUE`）：`d("k")` 等同 `d.Item("k")`、
`d("k") = "v"` 等同 `d.Item("k") = "v"`（与本机 VB6 实测一致）。

**错误号**：COM 失败按 VB6 的编号报错（本机 VB6 逐条实测过）——
`DISP_E_EXCEPTION` 看服务器给的 `EXCEPINFO.scode`：
- `0x800Axxxx`（服务器自己抛的 VB 错误）取低 16 位：`Scripting.Dictionary` 重复 `Add` 是 457、
  `Scripting.FileSystemObject` 的 `GetFile` 53 / `OpenTextFile` 76 / 无效驱动器 68；
- `E_INVALIDARG`（`0x80070057`）报 5（`WScript.Shell.Run ""`）；
- 其余系统包装码（`HRESULT_FROM_WIN32`）**原样当 `Long` 报**：`Run "不存在的程序"` 是 -2147024894、
  `Exec "C:\Windows"` 是 -2147024891、UNC 路径不通是 -2147024843。VB6 并没有「Win32 码换 VB 错误号」的表，
  只有 `E_INVALIDARG` 这一个特例。
成员不存在 438，参数个数不符 450，`CreateObject`/`GetObject` 类未注册 429，其余 440；
`Err.Description` 里是 QIDE 自己的中文说明加服务器原文。
没有默认属性的对象不能转成字符串（`CStr(对象)`、`"x" & 对象`、`s = 对象`、`Debug.Print 对象` 都报 450，与 VB6 一致）。

**`For Each` 与 `TypeName`**：`For Each` 遍历 COM 集合走 `_NewEnum`（`IEnumVARIANT`）的**活枚举器**——
每轮取一个元素，循环体里增删集合元素的效果由服务器自己的枚举器决定（与 VB6 相同，例如边遍历边
`Add` 时新键也会被枚举到）；`For Each k In d` 取到的是键（与 `Scripting.Dictionary` 的 VB6 行为一致）；
`TypeName(对象)` 报组件类名（`Dictionary`、`FileSystemObject`、`Connection`），服务器不支持 `IProvideClassInfo`
时退回默认接口名（`WScript.Shell` 是 `IWshShell3`），都取不到才是 `Object`。
服务器**没有 `_NewEnum`** 时（`WScript.Shell` 就是如此）按 VB6 的怪异行为复刻：`On Error Resume Next` 下
循环体照样跑一次（循环变量是 `Empty`、`Err.Number` 已是 438），随后 `Next` 报 92（「For 循环未初始化」），
循环体里写 `Exit For` 也一样；其它错误处理模式下直接把 438 交给处理过程。

**链式成员**：成员路径可以有任意多级，赋值也一样——
`rs.Fields.Append "id", 3`（先读 `rs.Fields` 再调 `Append`）、
`rs.Fields("id").Value = 1`（先按索引读出 `Field` 再设 `Value`）、`obj.Sub.Prop = v` 都可以用。
中间层**不带括号按属性取、带括号按调用**：脚本类同样适用——
`h.Self2().Value = 7`、`h.PropChain(2).Value = 25`、`Set h.Self2().Other = e` 都先把方法
或带参数的 `Property Get` 调用出来，再在**返回的对象**上赋值（本机 VB6 类模块工程逐条实测）。
`obj.` 后面的成员名允许是关键字（`Append` / `Type` / `Open` / `Close` 之类），与 VB6 一致。ADODB 的「建表 → 写值 → `GetRows`」全流程已用本机 VB6 逐行对比过（`GetRows` 的二维数组
第 1 维是字段、第 2 维是行）。

## 错误处理

```vb
Sub TryDivide()
    Dim x As Long
    On Error Resume Next
    x = 1 / 0
    If Err.Number <> 0 Then
        Debug.Print Err.Number, Err.Description
        Err.Clear
    End If
    On Error GoTo 0
End Sub

Sub WithHandler()
    On Error GoTo Failed
    Err.Raise 5, "WithHandler", "自定义错误"
    Exit Sub
Failed:
    Debug.Print "出错：" & Err.Description
    Resume Next
End Sub

TryDivide
WithHandler
Debug.Print Error(5)
```

- `Err.Number` / `Err.Description` / `Err.Source`、`Err.Raise`、`Err.Clear` 与 `Error(n)` 都可用。
- `Error n` 语句等价于 `Err.Raise n`：写入 `Err.Number`，描述取 VB 的默认文案
  （实测 `Error 5` → `Err.Description` 是「无效的过程调用或参数」，`Error 40080` → 兜底「定义的应用程序或对象错误」）。
- `Error$(n)` / `Err.Raise n` 的默认描述用的是 VB6 **运行时**错误表（本机实测 51 条，例如 3 号是「不执行 GoSub 而返回」、
  91 号是「未设置对象变量或 With block 变量」；未知号一律兜底「定义的应用程序或对象错误」）。
  注意这跟 VB6 IDE 编译对话框里那套 RT_STRING 文案不是同一张表，QIDE 的语法错误提示仍用自己的说法（更具体）。
- `Resume` 重新执行出错语句，`Resume Next` 继续下一条，`Resume 标签` 跳到标签。
- `On Error GoTo 0` 与 `On Error GoTo -1` 都会取消当前过程的错误处理；**执行任何 `On Error` 语句都会清空 `Err`**
  （本机 VB6 实测：`Resume Next` / `GoTo 0` / `GoTo -1` 三种写法都清，单纯读 `Err.Number` 不清）。
- 没有 `On Error` 时，运行时错误会中止脚本（输出面板里带行号，并自动跳到出错行）。

## 文件 I/O

```vb
Dim f As Long
f = FreeFile()
Open App.Path & "\data.txt" For Output As #f
Print #f, "第一行"
Write #f, 1, "二"
Close #f

Dim s As String
Open App.Path & "\data.txt" For Input As #1
Line Input #1, s
Debug.Print s
Close #1

Dim p As Point                                  ' 前面 Type 定义的记录
Open App.Path & "\rec.dat" For Random As #2 Len = 64
Put #2, , p        ' 记录号 1 起
Seek #2, 1
Get #2, , p
Close #2

Open App.Path & "\raw.bin" For Binary As #3
Dim v As Long
v = 123
Put #3, , v
Seek #3, 1
Get #3, , v
Lock #3, 1 To 4
Unlock #3, 1 To 4
Close #3
```

| 要点 | 说明 |
| --- | --- |
| 打开模式 | `Input` / `Output` / `Append` / `Binary` / `Random` |
| 文件号 | `As #n` 可省略，省略时自动分配最小空闲文件号（与 `FreeFile` 一致），之后用 `#1`、`#2`… 读写 |
| 相对路径 | `Open` / `Dir` / `FileLen` / `FileDateTime` / `Kill` / `FileCopy` / `MkDir` / `RmDir` / `Rename` 的相对路径都按**脚本所在目录**解析 |
| 当前目录 | `CurDir` / `ChDir` 只改脚本自己的视角，不会改编辑器进程的当前目录；`App.Path` 返回脚本目录 |
| `Get #` / `Put #` | 按变量声明类型（或表达式的动态类型）读写 1/2/4/8 字节，位置是 1 基字节偏移；目标可以是变量、数组元素或记录字段。转换函数写成表达式时按函数的结果类型定宽（`Put #1, , CByte(65)` 写 1 字节、`CInt` 2 字节、`CLng` 4 字节） |
| `Date` 存储 | `Date` 标量/UDT 字段按 8 字节 OLE Automation 序列读写；`Write #` 输出 `#2024/2/29[ 13:05:06]#`（与 `Date` 的显示一致），`Input #` 可读回 |
| 定长记录 | `For Random` 下 `Get`/`Put`/`Seek`/`Loc` 的位置都是记录号，默认记录长度 128 字节；单次读写超过记录长度报错误号 59 |
| `Loc(n)` | `For Random` 返回最近读写的记录号；其它模式返回**最后一个读写过的字节**的 1 基位置（刚打开、还没读写时是 0），与 VB6 一致 |
| 行尾 | `Print #` / `Write #` 的行尾都是 **CRLF**（本机 VB6 实测：`Print #1, "hello from script"` 之后 `FileLen` 是 19，`Width` 强制折行也一样）；`Line Input #` 两种行尾都能读 |
| 记录整块读写 | `Put #1, , p` / `Get #1, , p` 按 `StructLayout` 的字段偏移与对齐整块读写，`Len(p)` 给出字节数 |
| 变长 `String` | `Put #` 直接写字符字节、**没有长度前缀**（VB6 实测：`"AB"` 让文件长 2 字节，空串长 0 字节）；`Get #` 按变量**当前长度**（字节）读，当前是空串就一个字节也不读。QIDE 统一写 UTF-8 字节（VB6 用系统代码页，中文文本的字节数因此不同） |
| `Variant` 变量 | 写的是**带标记布局**：2 字节 VARTYPE + 内容（本机 VB6 逐字节比对）。`v = 5` 写 4 字节（`02 00 05 00`）、`v = "AB"` 写 6 字节（`08 00` + 2 字节长度 + 2 字节内容）、`Currency`/`Double`/`Date` 各 10 字节、`Boolean` 4 字节（`0B 00 FF FF`，注意不是 Win32 的 4 字节 BOOL）、`Single` 6 字节、`Empty` 只写 2 字节标记。`Get #` 读回同样的布局，并把变量类型改成标记里的类型（`Get` 一个 Integer 之后 `VarType` 是 2）。标记里是对象/数组时报错误号 458 |

其余文件函数：`EOF`、`LOF`、`Seek(n)`、`Loc(n)`、`FreeFile`、`FileLen`、`FileDateTime`、`Dir`、`Kill`、`FileCopy`、`Rename`、`MkDir`、`RmDir`、`Environ`、
`FileAttr(n, 1)`（返回打开模式码：`Input` 1 / `Output` 2 / `Random` 4 / `Append` 8 / `Binary` 32；文件号没打开先报 52，`returntype` 不是 1 才报 5）、`Input(n, #f)`（从 `For Input` 的文件读 `n` 个字符，不够时报 62；`For Binary` 上不报错、返回空串，`For Output`/`Append` 上报 54——都来自本机 VB6 实测）。

## 调用 Win32 API

```vb
Declare PtrSafe Function MessageBoxW Lib "user32" _
    (ByVal hWnd As LongPtr, ByVal text As String, ByVal caption As String, ByVal flags As Long) As Long

Declare PtrSafe Function GetTickCount Lib "kernel32" () As Long

Debug.Print GetTickCount()
Debug.Print MessageBoxW(0, "你好", "Q-IDE", 0)
```

`String` 形参按 W 版 API 的 `LPCWSTR` 传（本解释器只调用 W 版 API）。

```vb
Type RECT
    Left As Long
    Top As Long
    Right As Long
    Bottom As Long
End Type

Declare PtrSafe Function GetWindowRect Lib "user32" (ByVal hWnd As LongPtr, ByRef r As RECT) As Long
```

- `Declare ... Lib "库名" [Alias "..."]`，`PtrSafe` 可选；函数在运行时按名字（或别名）从 DLL 解析（W 版 API）。
- 支持 `ByRef` / `ByVal` 结构体（字段为整型、浮点、`String * n`、标量数组）；`ByVal` 结构体按 x64 ABI 传递（≤ 8 字节进寄存器，更大的传临时副本指针）。
- 参数支持最多 64 个整数、`Single`、`Double`、`Date` 标量的任意组合（`Date` 按原生 `Double` ABI 传递）；返回值可以是整数或 `Single` / `Double` / `Date`。
- 结构体字段支持整型/浮点、`String * n`、标量数组与 UDT 数组；结构体里的变长 `String` 仍不支持。
- `String * n` 在结构体与文件里占 `2n` 字节 UTF-16（本解释器只调用 W 版 API，与 VB6 的 ANSI `n` 字节不同）。

### AddressOf 回调

```vb
Declare PtrSafe Function EnumWindows Lib "user32" _
    (ByVal callback As LongPtr, ByVal lParam As LongPtr) As Long

Public Function OnWindow(ByVal hWnd As LongPtr, ByVal lParam As LongPtr) As Long
    Debug.Print hWnd
    OnWindow = 1          ' 返回 1 继续枚举
End Function

EnumWindows AddressOf OnWindow, 0
```

- 回调参数支持最多 64 个 `Byte` / `Integer` / `Long` / `Boolean` / `LongLong` / `LongPtr` / `Currency` / `Single` / `Double` / `Date` / `String` 形参及 `ByRef` UDT 形参（`Date` 按原生 `Double` ABI 传递；`ByVal String` 是 `LPCWSTR`，`ByRef String` 是 `LPWSTR *`）；返回值支持整数、`Single`、`Double` / `Date` 或 NUL 结尾的 `String`（`Sub` 视为 0）。
- 直接写在 `Declare` 实参里的 `AddressOf` 使用临时跳板，只在该次调用期间有效（`EnumWindows`、`InitOnceExecuteOnce` 等同步回调）；回调必须在脚本线程执行，来自其它线程的回调会返回默认值，不会切换线程进入解释器。
- `AddressOf` 存进 UDT 字段后再传给 `Declare`（如 `WNDCLASSW.lpfnWndProc`）会生成持久跳板，存活到脚本结束，因此 `RegisterClassW` + `CreateWindowExW` 这类窗口过程也能用。
- 数组形参不支持：原生指针本身不携带数组长度、下界与元素类型信息，无法安全还原为 VB 数组；可用 `LongPtr` 与独立长度参数表达原生接口，但解释器目前没有通用指针切片访问。脚本结束后系统再回调时会直接返回默认值，不再进入脚本（跳板上下文保留到进程结束）；旧回调也不会因后续运行复用同一栈地址而重新激活。
- x64 下句柄与指针要声明成 `LongPtr`（`Long` 只有 4 字节，放函数指针/句柄会被截断）；`Declare` 的 `As String` 参数按 UTF-16 传递，应配 W 版 API。`StrPtr(s)` 返回以 0 结尾的 UTF-16 缓冲区地址（`LongPtr`），缓冲区活到脚本结束，适合填 `lpszClassName` 这类指针字段。

### 数值与字符串转换的细节

- `CInt` / `CLng` 按银行家舍入取整，并检查目标类型范围（`CInt` 是 `Integer`、`CLng` 是 `Long`），
  越界报**错误号 6（溢出）**，非数字文本报**错误号 13（类型不匹配）**。
- `CBool` 与 `If` / `While` / `Do Until` 的条件只接受 `True` / `False`（大小写不敏感）与数字文本；
  空字符串或非数字文本报**错误号 13**（与 VB 一致，不再把任意非空字符串当成真）。
- `Str(x)` 与 VB 一致：非负数值带一个前导空格（`Str(5)` 是 `" 5"`、`Str(-5)` 是 `"-5"`），布尔值仍给 `True` / `False`；
  `|x| < 1` 时不写整数部分的 0（`Str(0.5)` 是 `" .5"`、`Str(-0.5)` 是 `"-0.5"` 的 VB 写法是 `"-.5"`），
  而 `CStr` 保留前导 0（本机 VB6 实测）。
- `Val` 支持 `&H` / `&O`（以及单独的 `&`）进制前缀，遇到无法解释的字符就停下：
  `Val("&HFF")` = 255、`Val("-12.5abc")` = -12.5、`Val("  -  1")` = -1（符号后面可以有空格）；D 也是指数标记（`Val("1D5")` = 100000），
  指数后面没有数字就不算指数（`Val("1e")` = 1、`Val("1.2.3")` = 1.2）。
  进制文本的取补码规则与进制字面量一致：装得进 16 位就当 Integer、否则按 Long
  （`Val("&HFFFF")` = -1、`Val("&HFFFF&")` = 65535、`Val("&H80000000")` = -2147483648）。`IsNumeric("&H10")` 也是 `True`。
- `Double` 按 VB6 的 **15 位有效数字**显示：`0.1 + 0.2` 打印 `0.3`、`1/3` 打印 `0.333333333333333`；
  定点写法的小数位超过 15 位、或整数位超过 15 位时改用科学计数法（`1E+15`、
  `1.23456789012345E-11`；`1.5E-14` 仍是 `0.000000000000015`）。
- `Space(n)` / `String(n, ch)` 的 `n` 上限是 16,777,216 个字符，超出报**错误号 14（字符串空间不足）**；
  `String` 的第二个参数可以是字符串（取首字符），也可以是字符代码（`String(3, 65)` 是 `"AAA"`）。
- `Dictionary` 的键查找走索引表，批量插入不再退化成 O(n²)。
- `CByte` 按银行家舍入取整并检查 `0..255`，越界报错误号 6；与 VB6 一样，`CByte(True)` 是 `255`、`CByte(False)` 是 `0`。
- `VarType` 返回 VB 的 `vb*` 类型码，数组是 `8192 + 元素类型码`（`Dim a(3) As Integer` → `8194`、`Array(1)` → `8204`）；
  标量按**表达式的静态类型**回答（`VarType(1)` 是 `2`、`VarType(40000)` 是 `3`），见「已知边界与完善优先级」第 11 条。
- `Hex` / `Oct` 的位数跟着参数类型走：`Hex(-1)` 给 16 位 `FFFF`、`Hex(-1&)` 给 `FFFFFFFF`、`Hex(-32768)` 给 `FFFF8000`；
  需要固定位数时用 `Hex(CInt(x))` 这类转换固定类型。
- `Sqr` 负数、`Log` 非正数报**错误号 5（无效的过程调用或参数）**，`Exp` 溢出与 `CDbl("1e400")` 报**错误号 6（溢出）**（本机 VB6 实测）。
- `Choose` 下标越界、`Switch` 没有条件成立都返回 `Null`；`Switch` 参数个数为奇数报错误号 5。
- **`Null` 怎么处理看形参类型**（本机 VB6 逐条实测）：`As String` / `As Long` 这类**非 `Variant`** 形参收到 `Null`
  报**错误号 94（无效使用 Null）**——`Asc(Null)`、`Chr(Null)`、`Val(Null)`、`Split(Null, ",")`、`Join(Null, ",")`、
  `Replace(Null, …)`、`StrReverse(Null)`、`InStrRev(Null, "a")`、`Space(Null)`、`String(Null, "x")`、`CInt`/`CLng`/`CDbl`/`CDate`；
  而 `Variant` 形参把 `Null` 原样传出去——`Trim`/`LTrim`/`RTrim`/`UCase`/`LCase`、`Left`/`Right`/`Mid` 的**第一个**实参、
  `Len`/`LenB`、`String(3, Null)`、`InStr(Null, "a")`、`InStr("a", Null)` 都返回 `Null`。
  少见的例外：`Format(Null, "0")` 是空字符串，`CStr(Null)` 报 94，`CStr(数组)` / `Len(数组)` 报 13，`InStr(开始, …, Null)` 报 13。
  数学函数也分两类（本机 VB6 实测）：`Abs`、`Int`、`Fix`、`Round`、`Hex`、`Oct` 返回 `Null`，
  而 `Sgn`、`Sqr`、`Exp`、`Log`、`Sin`、`Cos`、`Tan`、`Atn`、`Val` 收到 `Null` 报 94。
- 参数校验按 VB6：`Mid`/`InStr` 的起点必须是正数（0 或负数报 5）、`InStrRev` 的起点不能是 0、`Left`/`Right`/`Space`/`String` 的长度负数报 5、
  `Asc("")` 报 5。
- `StrConv` 只实现大小写（1/2/3）与全角（4）；`vbUnicode`(64) / `vbFromUnicode`(128) 对 Unicode 字符串是恒等变换，其他位报错误号 5。
  `vbProperCase`(3) 只把**空白**当词边界、并且只有词首那个字符本身是字母时才大写（本机 VB6 实测）：
  `StrConv("hello,world/x-y", 3)` 是 `Hello,world/x-y`、`StrConv("123abc", 3)` 是 `123abc`、`StrConv("a-b", 3)` 是 `A-b`。
- `TimeValue` / `CDate` 的时间文本支持 12 小时制：`AM`/`PM` 可以紧贴也可以空一格、大小写不限
  （`TimeValue("1:2:3 PM")` = 13:02:03、`TimeValue("9:05am")` = 9:05:00、`TimeValue("12:30AM")` = 0:30:00）；
  后缀只在 12 小时制内起作用，`TimeValue("13:00 PM")` 仍是 13:00:00。时分秒必须是十进制整数、且超范围即失败
  （`12:34:56.5`、`0:60`、`25:00` 都报**错误号 13**）。`TimeValue` 只接受字符串与 `Date` 值，
  `TimeValue(0.75)` / `TimeValue(1)` 报 13，`TimeValue(CDate(0.75))` 才是 18:00:00。
- `Rnd` / `Randomize` **不复刻** VB6 的伪随机序列（QIDE 用自己的 xorshift）：本机实测 VB6 同一段
  `Randomize 42` + 三次 `Rnd` 两次跑出的值都不一样（`0.3391077 / 0.6483685 / 0.1878102` 与
  `0.4311945 / …`），说明它的种子不只由实参决定、没法用固定种子做 oracle，因此这一项不做逐位对齐。
- `WeekdayName` / `MonthName` 输出中文名（本机 VB6 中文区域实测）：`WeekdayName(1)` 是「星期一」、缩写是「周一」、
  `MonthName(12)` 是「十二月」、缩写是「12月」。`WeekdayName` 省略 `firstdayofweek` 时按系统设置（中文系统从星期一起算），
  显式给 `1` 时 `WeekdayName(1, False, 1)` 才是「星期日」。
- `InStr` / `InStrRev` / `Replace` 的比较方式是 VB 的 `vbBinaryCompare`(0，默认) / `vbTextCompare`(1，不区分大小写) / `vbDatabaseCompare`(2，按二进制处理)：
  `InStr(1, "abc", "B", 1)` 是 2、`InStrRev("abcabc", "b", 3)` 是 2。`Replace` 的返回值**从 `start` 开始**（`start` 之前的内容不保留，与 VB6 实测一致），`count` 为 -1 表示全部替换；`find` 为空串时原样返回。
- `Split("")` 返回空数组（`UBound` 是 -1），与 VB6 一致。
- `Format` 支持命名格式 `General Number` / `Fixed` / `Standard` / `Percent` / `Scientific` / `Currency` / `Yes/No` / `True/False` / `On/Off`，
  以及带指数的自定义格式 `0.00E+00`；**进位是逢五进一**（`Format(0.5, "0")` 是 `1`、`Format(2.5, "0")` 是 `3`），
  与 `Round` 的银行家舍入不同，取舍在最短十进制表示上做（`Format(1.005, "0.00")` 是 `1.01`）。
  `Currency` 固定用 `￥` 前缀（本机 VB6 中文系统实测）、`Standard`/`Fixed` 固定用 `,` 作千位分隔符；
  `@`（右对齐补空格）/ `&`（不补齐）是文本占位符（`Format(1, "@@@")` 是 `"  1"`、`Format("abc", "&&&&")` 是 `abc`）。
- `Format` 的**自定义数值格式**（本机 VB6 逐条实测，39 条进了黄金用例）：
  - 数字占位符之间可以夹字面量，数字**右对齐**填进去：`Format(12345, "000-00")` 是 `123-45`、
    `Format(123, "00:00")` 是 `01:23`、`Format(12345, "###-###")` 是 `12-345`（多出的位数接在最左边占位符前）；
  - 整数占位符之间的逗号是**千位分组**（`Format(1234567, "#,##0")` 是 `1,234,567`、
    `Format(12345678, "000,000")` 是 `12,345,678`）；整数占位符之后、小数点之前的逗号是**缩放**
    （`Format(1234567, "0,")` 是 `1235`、`Format(1234567, "0,.0")` 是 `1234.6`），小数点之后的逗号忽略；
  - `%` 只有出现在最后一个占位符后面才乘 100（`Format(0.5, "0%")` 是 `50%`，`Format(0.5, "%0")` 是 `%1`）；
    `\x` 与 `"…"` 写转义字面量（`Format(123, "\$0")` 是 `$123`、`Format(5, "0.0""x""")` 是 `5.0x`）；
    段首的 `!` 会让整段按字面量输出（`Format(123, "!0000")` 是 `0000`，VB6 的怪癖）；
  - 没有占位符时整串按字面量输出（`Format(5, ",")` 是 `,`），`Format(123, ".00")` 是 `123.00`、
    `Format(0, "#.##")` 是 `.`；单个 `c` 是 `General Date`（`Format(123, "c")` 是 `1900/5/2`）。
- `Format` 的**自定义日期占位符**（与 VB6 逐条实测一致）：`y`（一年中的第几天）/`yy`/`yyyy`、
  `m`/`mm`（紧跟 `h`/`hh` 时是**分钟**）、`mmm`/`mmmm`（英文月份）、`d`/`dd`、`ddd`/`dddd`（英文星期）、
  `aaa`/`aaaa`（中文星期）、`h`/`hh`（有 `AM/PM` 时按 12 小时制）、`n`/`nn`、`s`/`ss`、
  `w`（星期号，星期日为 1）/`ww`（一年中的第几周）、`q`（季度）、`AM/PM`、`am/pm`、`A/P`、`a/p`；
  `"…"` 与 `\x` 写转义字面量（`Format(d, "yyyy""年""m""月""d""日""")` 是 `2024年2月29日`）。
- `RGB(r, g, b)` / `QBColor(n)` 返回 `Long` 颜色值 `r + g*256 + b*65536`：分量超过 255 按 255 处理
  （`RGB(256, 0, 0)` 是 255），负数报错误号 5；`QBColor` 只接受 0–15，越界报错误号 5（本机 VB6 实测）。
- `FormatNumber` / `FormatCurrency` / `FormatPercent` / `FormatDateTime` 与 VB6 中文区域实测一致：
  `FormatNumber(1234.5678)` 是 `1,234.57`、`FormatNumber(-1234.5, 2, , vbTrue)` 是 `(1,234.50)`、
  `FormatCurrency(1234.5)` 是 `￥1,234.50`、`FormatPercent(0.5)` 是 `50.00%`、
  `FormatDateTime(d, 1)` 是长日期、`(d, 4)` 是 `13:05`（命名格式 0–4，其他值报错误号 5）。
- `Spc(n)` / `Tab(n)` 只在 `Print` / `Debug.Print` 里有意义：`Spc` 补 n 个空格，
  `Tab(n)` 定位到第 n 列（1 基），目标列在当前列之前时先换行（`"abc"; Tab(2); "z"` 得到 `abc` 换行后 ` z`）。
  用于普通表达式会报「未定义的函数」，与 VB6 只允许出现在 `Print` 里一致。
- `Beep` 是语句（`Stmt::Call`），响一声系统默认提示音。
- `SaveSetting` / `GetSetting` / `DeleteSetting` / `GetAllSettings` 读写 QIDE 自己的文本文件
  （`%APPDATA%\gpui-first\vb-settings.txt`），VB6 写注册表；`GetSetting` 找不到时给默认值（省略默认值时是空字符串）。
  `GetAllSettings` 返回 0 基二维 `String` 数组（列 0 键名、列 1 值、按写入顺序），该节没有键时返回 `Empty`。
- `CallByName(对象, "成员", 调用方式[, 实参…])` 按名字后期绑定（本机 VB6 逐条实测）：
  `VbGet`(2) 取属性/字段、`VbLet`(4) 赋值、`VbSet`(8) 给对象、`VbMethod`(1) 调方法；名字不分大小写，
  实参按原表达式传入，所以 `ByRef` 形参照样能改回调用方（`CallByName(o, "RefArg", VbMethod, x)` 之后 `x` 会变）。
  错误号：成员不存在 / `Private` / 非法调用方式 / 字段当方法 → 438；`Sub` 当 `VbGet` 取、给只有 `Get` 的成员赋值、
  实参多于形参 → 450；少传必填实参 → 449；`VbLet`/`VbSet` 少了值 → 446；对象类型的字段用 `VbLet` 赋值 → 91；
  给普通字段用 `VbSet`、或给 `VbLet` 传了两个值 → 451；`Nothing` → 5；非对象（数字、字符串、空 `Variant`）→ 424。
  QIDE 自己的 `Dictionary`/`Collection` 是内置结构、没有 `IDispatch`，`CallByName` 对它们报 424
  （VB6 的 `Scripting.Dictionary` 是 COM 对象所以能过；用 `CreateObject("Scripting.Dictionary")` 创建的
  在 QIDE 里同样能过）。
- 支持 VB 标准常量（名字不分大小写）：`vbTrue`(-1) / `vbFalse`(0) / `vbUseDefault`(-2)、
  `vbCr` `vbLf` `vbCrLf` `vbTab` `vbNullChar` `vbNullString`、`vbBinaryCompare` `vbTextCompare` `vbDatabaseCompare`、
  `vbGeneralDate`…`vbShortTime`、`vbSunday`…`vbSaturday` `vbFirstJan1` `vbFirstFourDays` `vbFirstFullWeek`、
  `vbOKOnly` / `vbYesNo` / `vbOK` / `vbYes` 等 `MsgBox` 常量、`vbObjectError`、`vbEmpty`…`vbArray`（`VarType` 类型码）、
  `vbMethod`(1) / `vbGet`(2) / `vbLet`(4) / `vbSet`(8)（`CallByName` 的调用方式）、
  `vbNormal`(0) / `vbReadOnly`(1) / `vbHidden`(2) / `vbSystem`(4) / `vbVolume`(8) / `vbDirectory`(16) / `vbArchive`(32) / `vbAlias`(64)（文件属性）。
  注意 `VarType(vbTrue)` 与 VB6 一样是 `3`（`Long`），不是 `Boolean`。
- `CSng` 会把值真正窄化成 32 位浮点（后续运算与 VB6 一致）；打印时按 VB6 的 **7 位有效数字**（`CSng(1.23456789)` 是 `1.234568`），
  但 `VarType` 仍报 `Double`（QIDE 没有独立的 `Single` 值类型）。
- `IsMissing` 只对**调用时省略的可选参数**返回 `True`；参数一旦被赋值就恢复为 `False`。
- `Partition(值, 起点, 终点, 间隔)` 与 VB6 一致：区间为 `[起点 + k×间隔, 起 + k×间隔 + 间隔 - 1]`，
  上界超过终点时截到终点；两段按「终点 + 1 的位数」右对齐补空格（`Partition(5, 0, 99, 10)` 是 `"  0:  9"`）；
  值小于起点时前半段留空、后半段是 `起点 - 1`，大于终点时前半段是 `终点 + 1`、后半段留空；
  起点 < 0、终点 ≤ 起点或间隔 < 1 报错误号 5。

### 财务函数

`SLN` `SYD` `DDB` `FV` `PV` `Pmt` `NPer` `IPmt` `PPmt` `NPV` `IRR` `MIRR` `Rate`，参数与返回值都是 `Double`。

```vb
Print CStr(Pmt(0.05, 10, 10000))            ' -1295.04574965457
Print CStr(FV(0.05, 10, -100, 0, vbTrue))   ' 1320.67871623263（期初付款）
Print CStr(DDB(10000, 1000, 5, 5))          ' 296（最后一期不超过「期初净值 − 残值」）
Print CStr(DDB(10000, 1000, 5, 4.5))        ' 669.251522224642（支持小数期）
```

- `type` 形参（`FV`/`PV`/`Pmt`/`NPer`/`IPmt`/`PPmt`/`Rate` 的第 5 或第 6 个参数）**非 0 即期初付款**：
  `1`、`True`（-1）都按「期初」算，与 VB6 一致。期初付款时第 1 期利息 `IPmt` 是 0。
- `NPV`/`IRR`/`MIRR` 的第 1 个参数是一维数值数组（`NPV(rate, values)`）。`NPV` 把 `values(0)` 当成**第 1 期**
  （`values(i)` 除以 `(1 + rate) ^ (i + 1)`），不是第 0 期——与 VB6 相同。
- `IRR` 的 `guess` 默认 0.1；`Rate` 的 `guess` 也默认 0.1。两者都是迭代解（割线法），
  与 VB6 的差在 1e-11 量级以内（VB6 自身收敛到 1e-7 就停，末几位本来就不稳定）；
  传不同的 `guess` 也可能得到末几位略有差异的结果。
- 零利率恰好是解时（`Rate(10,-100,1000)`：10 期各付 100 正好还清 1000）QIDE 报**错误号 5**，
  与 VB6 在默认 `guess = 0.1` 下的行为一致；VB6 换个 `guess` 偶尔会收敛到 1e-9 量级的值
  （`Rate(10,-100,1000,0,0,0.5)` = 3.27903231982296E-09），这种迭代偶然性 QIDE 不复刻。
- 错误号（本机 VB6 实测）：`SLN` 的 `life` 为 0、`SYD`/`DDB` 的 `life` ≤ 0 或 `period` 不在 `1..life`、
  `DDB` 的 `factor` ≤ 0、`Pmt` 的 `nper` 为 0、`NPer` 的 `pmt` 为 0、`IPmt`/`PPmt` 的 `per` 越界、
  `IRR` 没有正负号混合、`Rate` 求解失败或零利率恰好是解，都报**错误号 5**；
  `MIRR` 没有负现金流（除数为零）报**错误号 11**；实参是 `Null` 报**错误号 94**、非数值文本报**错误号 13**。
- 数值型字符串按 VB 的隐式转换参与计算（`FV("0.05", 10, -100)` 与 `FV(0.05, 10, -100)` 相同）。

## 命令行运行（`qide-run`）

不开界面也能跑脚本（`cargo build` 会同时产出 `target\debug\qide-run.exe`，只链接解释器，约 3 MB）：

```powershell
qide-run demo.vb                   # 只给路径就等于 run（给文件关联用）
qide-run run  demo.vb              # 脚本输出走 stdout，诊断走 stderr
qide-run run  demo.vb --json       # 每行一个 JSON 事件，供程序 / agent 解析
qide-run check demo.vb --json      # 只做语法与语义检查，不执行
```

| 选项 | 说明 |
| --- | --- |
| `--json` | 输出 JSONL 事件（`start` / `line` / `finished` / `interrupted` / `issue` / `checked`） |
| `-q, --quiet` | 不输出脚本的 `Print` / `Debug.Print` |
| `--max-steps N` / `--max-depth N` | 覆盖步数上限（默认 20000000）与过程递归上限（默认 200） |
| `--timeout 30s` | 超时后中断脚本；也接受 `500ms`、`2m`，裸数字按秒 |
| `--include-dir DIR` | `#Include` 在脚本目录找不到时再搜这里（替代 exe 同级的 `assets/`） |
| `--arg 文本` | `Command()` 返回的内容 |
| `--stats` | 运行结束后输出语句/表达式/调用/数组访问/变量读取的次数（用于决定优化顺序） |
| `--trace` | 逐条输出执行轨迹：每执行一条语句写一行 `» 第 N 行`（普通模式走 stderr，`--json` 模式是 `{"type":"trace"}` 事件，stdout 仍只有脚本输出） |
| `--ui` / `--no-ui` | 允许 / 禁止 `MsgBox`、`InputBox` 弹窗 |
| `--pause` / `--no-pause` | 结束后等待回车 |
| `--ui`、`--pause` 的默认值 | 「人直接运行」时开启，供 agent 调用时关闭，见下 |

**什么时候算「人直接运行」**：stdout 连着控制台（没有被管道接走），并且这个控制台是给自己新开的（双击启动时控制台里只有自己；从 `cmd`/PowerShell 里启动时还有宿主进程）。这种情况下默认允许弹窗、结束时停住等回车，避免双击 `.vb` 时窗口一闪就没；反之（`--json`、输出被重定向、从终端启动）默认不弹窗、不暂停。

把 `.vb` 的打开方式指向 `qide-run.exe`（命令行写 `"...\qide-run.exe" "%1"`）即可双击运行；只想检查语法时用 `qide-run check 文件`。

退出码：`0` 成功、`2` 语法或语义问题、`3` 运行时错误、`4` 超时或 Ctrl+C、`5` 读不到脚本 / 内部错误、`64` 参数用法错误。

`--json` 的结束事件带结构化错误，程序不必解析中文文本：

```json
{"type":"finished","ok":false,"kind":"runtime","number":6,"line":12,"message":"溢出"}
```

相对路径按脚本所在目录解析（与编辑器里运行一致）；控制台代码页会切到 UTF-8，`stdout` 可直接重定向到文件。

## 与编辑器的配合

| 入口 | 说明 |
| --- | --- |
| 运行（`F5`） | 在后台线程解释执行当前标签里的脚本，`Debug.Print` / `Print` 输出到输出面板 |
| 调试运行（`Ctrl+F5`） | 命中 `F9` 断点或暂停请求时停下，可看变量快照、调用栈、监视表达式 |
| 运行参数… | 内容由脚本里的 `Command()` 读取 |
| 检查语法 | 只解析不执行，错误写进输出面板 |
| 停止脚本（`Shift+F5`） | 置中断标志：解释器会在语句边界停下，`MsgBox` / `InputBox` 创建的对话框也会被关闭 |
| 语义检查 | `Option Explicit` 下的未声明变量、`ReDim` 未声明数组、未定义的过程名，作为编辑器诊断实时提示 |

运行限制：默认最多执行 20,000,000 条语句、过程嵌套 200 层（`RunOptions`），超限报错而不是卡死界面；
语法分析的嵌套上限是 96 层（防止超深嵌套把栈耗尽，正常脚本远达不到）；
递归到线程栈空间不足时同样报错（错误号 28），不会让程序崩溃。

## 已知边界与完善优先级

以下按通用 VB6/VBA 脚本里的估计使用频率排序，不代表本程序的遥测统计：

1. **类成员访问控制（已完善）**：字段默认 `Private`，方法和属性默认 `Public`；显式修饰符生效，同类成员可以访问私有成员。
2. **COM 自动化扩展（`GetObject` 文件/moniker、命名/ByRef、任意维数与强类型 SAFEARRAY、链式成员、参数化属性与默认成员、错误号、`WithEvents` 事件、`For Each` 活枚举器、`DoEvents` 同步事件、`TypeName` 已完善）**：已支持 `CreateObject`、ROT 活动对象和 moniker `GetObject(path, class)`、Automation 属性读写与位置/命名参数调用；成员名带实参时先按属性取、再按方法调（`d.Item("k")` 与 `d.Add "k", "v"` 都能用），对象后直接接实参走默认成员（`d("k")`、`d("k") = "v"`），成员路径可多级且成员名可以是关键字（`rs.Fields.Append "x", 3`、`rs.Fields("id").Value = 1`），`Dim WithEvents x As Object` 的变量会挂接 COM 事件并分派给 `x_事件` 处理过程（语句边界与 `DoEvents` 两处，后者同步执行完），失败按 VB6 报错号（重复 `Add` 457、成员不存在 438、参数个数不符 450、其余 440），`For Each` 走 `_NewEnum` 的活枚举器取键，`TypeName` 报组件类名（`Dictionary` / `FileSystemObject` / `Connection`，WSH 这类服务器退回接口名 `IWshShell3`），数组按声明类型封送成对应元素类型的 `SAFEARRAY`（多维也一样）。UDT 记录封送尚不支持。
3. **日期与货币类型（基础 Date/Currency 已完善）**：`Currency` 是四位小数定点数；`Date` 是独立类型，使用 OLE Automation 序列表示，支持日期字面量、转换、日期内置函数、算术、8 字节二进制存储、Win32 Double ABI 与 COM `VT_DATE` 封送。日期显示、`Format` 的命名格式与自定义日期占位符、日期文本解析都已按 VB6 实测对齐（见第 12～15 条）；剩负日期序列（1899-12-30 之前）的细节没有逐条对齐。
4. **二进制文件 I/O（变长 `String` 与 `Variant` 已完善）**：`Put #` 按 VB6 实测的规则直接写字符字节、没有长度前缀，`Get #` 按变量当前长度（字节）读（UTF-8 字节，不是 VB6 的系统代码页）；`Variant` 变量按「2 字节 VARTYPE + 内容」的带标记布局读写（逐字节比对过），标记里是对象/数组报错误号 458。
5. **Win32 调用 ABI（标量混合与 UDT 数组已完善）**：结构体里的变长 `String` 仍不支持；一次声明最多 64 个参数。
6. **回调边界**：最多支持 64 个整数/浮点/字符串参数，支持整数/浮点/字符串返回与 ByRef UDT 参数；数组形参不支持，且持久回调在脚本结束后不再进入解释器。
7. **接口实现限制**：支持类级 `Implements` 与 `接口名_成员名` 私有实现分派，并在实时检查里做成员一致性与签名一致性诊断（漏实现接口的公开成员、写了接口没有的 `接口名_成员名`、过程形式/参数/返回类型与接口不一致都会报出）；接口变量的静态类型和完整 COM 类接口机制尚未实现。
8. **多文件类引用（已完善）**：`As 类型名` 与 `Implements 接口名` 支持**前向引用**，`Type` / `Enum` / `Class` 可以写在使用点之后（含 `#Include` 进来的定义），只要在同一个脚本里就行；同名的 `Type` 不能直接或间接包含自身，这种循环定义在解析结束时报语法错误。
9. **模块级访问控制（已确认按单模块语义处理）**：`#Include` 是**文本展开**，整个脚本算一个模块，所以模块级 `Public` / `Private` 与 VB6 单模块内的行为一致（同一模块的过程互相可见，修饰符只影响语法外的东西）；需要跨模块隔离的只有类成员，那部分已按 VB6 实现（字段默认 `Private`、方法默认 `Public`，同类可访问私有成员）。若将来引入多模块工程，再补真正的隔离。
10. **数字字面量类型后缀（已完善）**：十进制字面量可以带 `%`（Integer）/ `&`（Long）/ `!`（Single）/ `#`（Double）/ `@`（Currency）后缀，与进制字面量一致；注意 `!` 只影响写法，值仍是 `Double`（解释器没有独立的 Single 值）。
11. **整数宽度与 `Single` 打印（字面量、进制字面量、表达式、`Variant` 内容类型、`For Each` 元素类型、整数运算溢出、`Single` 打印均已对齐）**：`VarType` / `TypeName` / `Hex` / `Oct` 现在按**表达式的静态类型**回答，规则逐条来自本机 VB6 实测：字面量装得进 Integer 就是 Integer（`VarType(32767)`=2、`VarType(32768)`=3）、类型后缀生效（`123&` 是 Long、`1.5!` 是 Single、`&HFFFF&` 是 Long）、**进制字面量按最小整数宽度取补码**（`&HFFFF` 是 -1、`&H8000` 是 -32768、`&HFFFFFFFF` 是 -1 且 `VarType` 是 3、`&HFFFF&` 是 65535）、运算符按 VB6 的提升规则（`1 + 1` 是 Integer、`1& + 1` 是 Long、`Byte + Byte` 是 Byte、`1 + CSng(1)` 是 Single、`1& + CSng(1)` 是 Double、`CCur(1) + CDbl(1)` 是 Currency、`1 / 2` 与 `2 ^ 3` 是 Double、比较与 `Like` 是 Boolean、`Null` 参与运算时不推断），因此 `Hex(-1)` 给 16 位 `FFFF`、`Hex(-1&)` 给 `FFFFFFFF`、`Hex(-32768)` 给 `FFFF8000`、`Hex(-200)` 给 `FF38`。**`Variant` 变量也按赋值时的表达式类型报告**（赋值时把静态类型记在槽里）：`v = i`（Integer）之后 `VarType(v)` 是 2、`v = CByte(1)` 17、`v = True` 11、`v = CCur(1)` 6、`v = 40000` 3、`v = 1.5` 5、`v = "x"` 8，隐式 `Dim x` 同理。**`For Each` 的循环变量取数组的元素声明类型**（Integer 数组 → 2、Byte → 17、String → 8）。**整数运算溢出报错误号 6**（实测 `32767 + 1`、`32767 * 2`、`2147483647 + 1`、`-i`（Integer 的 -32768）都报；`-32768 - 1` 因为字面量已是 Long、`c + c`（Long 30000）、`200 + 200`、`32767 Mod -1` 都不报）：`+`/`-`/`*`/`\` 与一元 `-` 的结果超出 **Integer/Long** 范围时报错。**`Single` 按 7 位有效数字打印**（`Debug.Print` / `Print #` 以及 `&` 拼接：`CSng(1.23456789)`→`1.234568`、`CSng(12345678)`→`1.234568E+07`、`CSng(0.00001)`→`0.00001`、`CSng(0.000123456789)`→`1.234568E-04`；`CStr` / `Str` 也按 7 位（`CStr(CSng(1.23456789))`→`1.234568`、`Str(CSng(0.5))`→`" .5"`））。
    **容器里也记内容类型**（本机 VB6 实测：`arr(0) = CByte(9)` 之后 `VarType(arr(0))` 是 17；`Array(CByte(1), 2)` 的第一个元素是 17、第二个是 2；`Collection.Add CByte(7)` 之后 `For Each` 拿到 17，`Dictionary` 同理——`d("k") = CByte(1)` 之后 `VarType(d("k"))` 是 17、`d.Add "k2", CSng(1.5)` 之后是 4），实现是 `VbArray` / `VbCollection` / `VbDictionary` 各带一份元素内容类型，只在 `Variant` 容器上记录、字面量下标才做静态查询。**`Byte` 的运算溢出也报错误号 6**（`CByte(200) + CByte(200)`）。
    仍然不同的是**值的传递路径**：`Value` 本身不带窄类型，`ByVal v As Variant` 参数、UDT 与类里 `As Variant` 的字段、`ParamArray` 打包的数组元素都各自记了一份内容类型（`Narrow(i)` 是 2、`Narrow(CSng(1.5))` 是 4、`u.f = i` 之后 `VarType(u.f)` 是 2、`c.P = i` 之后 `VarType(c.P)` 是 2）；**返回 `Variant` 的函数**、`IIf`/`Choose`/`Switch`（按选中的那个实参算，`IIf(True, i, s)` 是 2、`IIf(False, i, s)` 是 4）、`Collection.Item`/`c(1)`、`Property Get` 的返回声明类型、`With` 里的字段这些**经过调用/成员访问**的路径，由 `static_type` 与 `Runtime::result_narrow` 补上（本机 VB6 逐条实测）。剩下只有真正拿不到类型的地方：`Declare` 的 `As Any` 实参按声明类型封送、`Single` 没有独立的值类型（`VarType(CSng(1))` 靠静态推断才对）。
12. **`Format` 的日期命名格式（已对齐 VB6 中文区域）**：`General Date` / `Long Date` / `Medium Date` / `Short Date` / `Long Time` / `Medium Time` / `Short Time` 都可用，参数先按 `CDate` 的规则转成日期（数字当序列、文本会尝试解析）。输出固定、不读系统区域设置，取本机 VB6（中文区域）实测的写法：
    `General Date` = `2024/2/29 13:05:06`（时间部分为 0 时只给日期 `2024/2/29`；日期部分为 0 时只给时间 `0:00:00`）、
    `Long Date` = `2024年2月29日`、`Medium Date` = `24-02-29`、`Short Date` = `2024/2/29`、
    `Long Time` = `13:05:06`、`Medium Time` = `01:05 下午`（12 小时制 + 上午/下午）、`Short Time` = `13:05`。
    `Date` 值本身的显示也是这套 `General Date`；数值命名格式（`Standard`/`Fixed`/`Currency`/`Percent`/`Scientific`/`Yes/No`/`True/False`/`On/Off`）与自定义格式（含 `0.00E+00`、`;` 分段、`%`）同样可用。
13. **`DatePart` 的周号（已对齐，年末两天有偏差）**：`yyyy`/`q`/`m`/`y`/`d`/`w`/`ww`/`h`/`n`/`s` 与可选参数 `firstdayofweek`、`firstweekofyear` 都支持（`ww` 的第 2、3 种首周规则按「新年至少 4 天」「新年里完整的第一周」计算）。已知偏差：VB6 自己在**年末最后一周**的表现不自洽（`DatePart("ww", #2019-12-29#, 1, 2)` 给 53，而同一个星期的 `#2019-12-30#` 给 1），QIDE 一律按「新年的第 1 周」处理，因此这类日期可能比 VB6 小 52。
14. **`Format` 的取舍、`Val`、`LenB`、`DateSerial`（均已对齐 VB6）**：`Format` 的逢五进位在**最短十进制表示**上做（`Format(1.005, "0.00")` 是 `1.01`、`Format(2.675, "0.00")` 是 `2.68`，直接按二进制乘 100 会给 `1.00`）；`Val("1e")` / `Val("1E+")` 是 1（指数后面没有数字就不算指数）、`Val("1.2.3")` 是 1.2、`Val("1D5")` 是 100000；`LenB` 是 `Len` 的两倍（VB 的字符串是 UTF-16，`LenB("abc")`=6、`LenB("中文")`=4）；`DateSerial` 的月、日允许溢出（`DateSerial(2024, 2, 30)` 是 2024-03-01、`DateSerial(2024, 3, -1)` 是 2024-02-28），两位年份按 0–29 → 2000–2029、30–99 → 1930–1999 展开。
15. **日期文本的解析顺序（已对齐 VB6）**：三个数字段依次按「年-月-日」「月-日-年」「日-月-年」尝试，取第一个合法组合——`CDate("24-2-29")` 是 2024-02-29、`DateValue("3/4/2024")` 是 2024-03-04、`DateValue("31/12/2024")` 是 2024-12-31（前两种写法都不合法时才按日-月-年）；两位年份同样按 1930/2000 规则展开，仍按严格日历校验（`IsDate("2024-2-30")` 是 `False`）。
16. **`Asc` / `Chr` 走 Unicode 码位（不做 ANSI 代码页转换）**：VB6 的 `Asc` 会把字符转成系统代码页（中文系统是 936）再取字节，因此非 ASCII 字符的结果依赖区域：本机 VB6 实测 `Asc("中")` 是 `-10544`（0xD6D0 按有符号 16 位解释）、`Asc(Chr(200))` 是 `63`（U+00C8 在 936 里是问号）。QIDE 内部是 UTF-8、不模拟代码页，`Asc` 直接给 Unicode 码位（`Asc("中")` 是 `20013`，等同 `AscW`）；需要字节值时用 `AscW` 或自己按编码换算。
17. **尚未实现的语句与声明（语法层完全没有，不是语义偏差）**：按「粘贴真实 VB6 源码时多久会撞上」排序——
    `Event 名字(ByVal 参数 As 类型)`（`RaiseEvent` 只能发 ad-hoc 事件名，参数由同类 `<类名>_<事件名>` 的同名形参接）、
    **模块级 `Dim WithEvents x As 脚本类` 静默无效**（只有 COM 对象会挂接事件，脚本类对象一条事件也收不到且不报错）、
    独立定长字符串 `Dim s As String * 8`（UDT 成员里的 `String * N` 可用）、命名实参 `x.M y:=1`、
    `#If … #End If` 条件编译、脚本类的默认成员（要 `Attribute Item.VB_UserMemId = 0` 之后才能写 `c(3)`，
    COM 对象支持；`Attribute` 行本身现在会被跳过，但不产生默认成员）。
    另有两处小偏差：未初始化动态数组的 `LBound(a)` 报 5（VB6 报 9）；读取一个从未出现过的名字一律报
    「未定义的变量」（VB6 会当场建一个空变量，QIDE 为抓拼写错误保留报错——`DefInt` 之后只影响
    `VarType` / 赋值转换的回答）。
- x64 下把 `HWND` / `HDC` / 函数指针等声明成 `Long` 会被截断，必须用 `LongPtr`。

## 完整示例：写一个日志文件

```vb
Option Explicit

Declare PtrSafe Function GetTickCount Lib "kernel32" () As Long

Sub WriteLog(ByVal text As String)
    Dim f As Long
    f = FreeFile()
    Open App.Path & "\run.log" For Append As #f
    Print #f, Format(Now, "yyyy-mm-dd hh:nn:ss") & " " & text
    Close #f
End Sub

Dim i As Long, total As Long
For i = 1 To 100
    total = total + i
Next i

WriteLog "合计 " & total
Debug.Print "用时（毫秒）：", GetTickCount()
MsgBox "计算完成，合计 " & total, 64, "Q-IDE"   ' 64 = vbInformation
```
